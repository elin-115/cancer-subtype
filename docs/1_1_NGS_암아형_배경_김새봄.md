# NGS·암 아형 배경 조사

## 조사 목적

암의 기본 개념과 NGS 기술을 이해하고, 암을 어떤 기준으로 분류하며 분자적 특징에 따라 어떻게 아형을 구분하는지 파악한다.

---

## 1. 암(Cancer)이란?

암은 세포의 성장과 분열을 조절하는 기능에 이상이 생겨 비정상적인 세포가 증식하는 질병이다.

- **정상 세포:** 성장·분열·사멸이 조절됨
- **암세포:** 성장 조절 기능이 손상되어 비정상적으로 증식함
- **진행 과정:** 주변 조직을 침범하거나 다른 장기로 전이할 수 있음

### 주요 발생 원인

- DNA 염기서열 변이
- 염색체 수와 구조의 이상
- 유전자 발현을 조절하는 후성유전학적 변화

> 단, 모든 유전자 변이가 암을 일으키는 것은 아니다. 암 발생에는 여러 변화가 복합적으로 작용한다.

---

## 2. NGS(Next-Generation Sequencing)란?

NGS는 차세대 염기서열 분석 기술로, DNA 또는 RNA의 염기서열을 대량으로 동시에 읽어내는 기술이다.

### 기본 분석 과정

1. 암 조직 또는 혈액 등 검체 확보
2. DNA/RNA 추출 및 라이브러리 제작
3. NGS 염기서열 분석
4. 생물정보학 분석
5. 유전자 변이 및 발현 특성 파악

### NGS로 확인할 수 있는 주요 정보

| 분석 항목 | 의미 |
|---|---|
| SNV | 단일 염기 변이 |
| InDel | 염기의 삽입 또는 결실 |
| CNV | 유전자 복제 수 변화 |
| Fusion | 서로 다른 유전자의 융합 |
| RNA 발현량 | 유전자가 얼마나 발현되는지 |

NGS는 암을 직접 확진하는 기술이라기보다 암의 유전적·분자적 특성을 분석하는 수단이다.

---

## 3. 암의 유형은 어떤 것이 있을까?

암은 발생한 장기와 조직, 세포의 종류 등에 따라 구분할 수 있다.

| 암의 유형 | 발생 부위 및 특징 |
|---|---|
| 암종(Carcinoma) | 피부·장기 등의 상피세포 |
| 육종(Sarcoma) | 뼈·근육·지방 등 결합조직 |
| 백혈병(Leukemia) | 혈액을 만드는 조직 |
| 림프종(Lymphoma) | 림프계 세포 |
| 흑색종(Melanoma) | 멜라닌을 만드는 세포 |

예를 들어 폐에서 발생한 암은 폐암, 유방에서 발생한 암은 유방암이라고 부르는 것처럼 발생 장기에 따라서도 구분할 수 있다.

---

## 4. 암 아형(Cancer Subtype)이란?

같은 장기에서 발생한 같은 종류의 암이라도 유전자 변이, 유전자 발현, 세포의 특성 등이 서로 다를 수 있다.

이렇게 생물학적·분자적 특징이 비슷한 암을 묶어 세분화한 그룹을 암 아형이라고 한다.

### 4.1 유방암의 분자적 아형

유방암은 다음과 같은 분자적 아형으로 분류할 수 있다.

- Luminal A
- Luminal B
- HER2-enriched
- Basal-like

이 분류에는 주로 에스트로겐 수용체(ER), 프로게스테론 수용체(PR), HER2, Ki-67 등의 정보와 유전자 발현 특성이 활용된다.

### 4.2 대회 SUBCLASS 26개 라벨

#### 4.2.1 대회 SUBCLASS 26개 라벨 설명

본 대회의 SUBCLASS는 대부분 TCGA(The Cancer Genome Atlas)에서 사용하는 암종 코드로 구성되어 있다.

이는 유방암, 폐암, 간암 등 암이 발생한 장기나 조직을 구분하는 분류이다.

따라서 Luminal A·B, CMS와 같이 동일 암종 내부의 분자적 특성을 기준으로 세분화한 아형과는 구분해야 한다.

| 코드 | 한글 암종명 |
|---|---|
| ACC | 부신피질암 |
| BLCA | 방광 요로상피암 |
| BRCA | 유방암 |
| CESC | 자궁경부암 및 자궁경부 내막 선암 |
| COAD | 결장 선암 |
| DLBC | 미만성 거대 B세포 림프종 |
| GBMLGG | 교모세포종 및 저등급 신경교종 |
| HNSC | 두경부 편평세포암 |
| KIPAN | 신장암 통합 분류(KICH, KIRC, KIRP) |
| KIRC | 신장 투명세포암 |
| LAML | 급성 골수성 백혈병 |
| LGG | 저등급 신경교종 |
| LIHC | 간세포암 |
| LUAD | 폐 선암 |
| LUSC | 폐 편평세포암 |
| OV | 난소 장액성 선암 |
| PAAD | 췌장 선암 |
| PCPG | 갈색세포종 및 부신경절종 |
| PRAD | 전립선 선암 |
| SARC | 육종 |
| SKCM | 피부 흑색종 |

#### 4.2.2 26개 SUBCLASS 라벨의 카테고리별 분류

발생 부위 및 계통에 따라 26개 라벨을 다음과 같이 구분할 수 있다.

| 카테고리 | 라벨 | 암종 |
|---|---|---|
| 뇌·중추신경계 | GBMLGG, LGG | 교종 통합 그룹, 저등급 교종 |
| 신장 | KIPAN, KIRC | 신장암 통합 그룹, 신장 투명세포암 |
| 소화기계 | COAD, STES, LIHC, PAAD | 대장암, 위·식도암, 간암, 췌장암 |
| 호흡기계 | LUAD, LUSC | 폐 선암, 폐 편평세포암 |
| 생식기계 | BRCA, CESC, OV, PRAD, TGCT, UCEC | 유방암, 자궁경부암, 난소암, 전립선암, 고환암, 자궁내막암 |
| 내분비·흉선 | ACC, PCPG, THCA, THYM | 부신피질암, 부신경절종 관련 종양, 갑상선암, 흉선종 |
| 피부 | SKCM | 피부 흑색종 |
| 혈액·림프계 | LAML, DLBC | 급성 골수성 백혈병, 미만성 거대 B세포 림프종 |
| 기타 장기·조직 | BLCA, HNSC, SARC | 방광암, 두경부 편평세포암, 육종 |

#### 4.2.3 조직학적 유형에 따른 공통점

발생 장기가 다르더라도 조직학적 특징이 비슷한 암들이 존재한다.

| 조직학적 유형 | 관련 라벨 예시 | 특징 |
|---|---|---|
| 선암 | LUAD, COAD, PAAD, PRAD | 분비 기능을 가진 상피세포에서 유래 |
| 편평세포암 | LUSC, HNSC, CESC 일부 | 편평상피세포에서 유래 |
| 신경계 종양 | GBMLGG, LGG | 신경교세포 계열과 관련 |
| 혈액·림프계 종양 | LAML, DLBC | 혈액세포 또는 림프구 계열에서 유래 |
| 육종 | SARC | 뼈, 근육, 지방 등 결합조직 계열에서 유래 |
| 흑색종 | SKCM | 멜라닌을 생성하는 멜라닌세포에서 유래 |

#### 4.2.4 합본 라벨 설명

일부 SUBCLASS는 여러 암종을 하나의 그룹으로 합친 통합 분류이다.

- **GBMLGG:** GBM(교모세포종)과 LGG(저등급 신경교종)를 합친 분류
- **KIPAN:** KICH(신장 혐색소세포암), KIRC(신장 투명세포암), KIRP(신장 유두상세포암)를 합친 신장암 분류
- **STES:** STAD(위 선암)와 ESCA(식도암)를 합친 분류

> **주의:** KIRC와 LGG는 각각 KIPAN과 GBMLGG에 포함되는 암종이지만, 데이터 라벨 목록에는 개별 코드도 별도로 존재한다. 따라서 26개 라벨을 모두 서로 완전히 독립적인 암종으로 이해해서는 안 된다.

## 5. 아형은 어떤 기준으로 구분할까?

암 아형은 하나의 기준만으로 정해지는 것이 아니라 여러 정보를 종합해서 구분한다.

| 구분 기준 | 확인하는 정보 |
|---|---|
| 유전자 변이 | EGFR, KRAS, BRAF, TP53 등 |
| 유전자 발현 | 특정 유전자가 얼마나 발현되는지 |
| 단백질 발현 | HER2, ER, PR 등 |
| 염색체 변화 | 염색체 수·구조 및 유전자 복제 수 |
| 분자 경로 | 세포 성장, 면역, 대사 등의 활성 상태 |

### 실제 사례: 대장암의 CMS 아형

대장암은 유전자 발현 패턴 등을 분석해 4가지 주요 분자 아형으로 분류할 수 있다.

| 아형 | 주요 특징 |
|---|---|
| CMS1 | 면역 반응 활성, MSI 관련 특징 |
| CMS2 | WNT·MYC 신호 경로 활성 |
| CMS3 | 세포 대사 이상 |
| CMS4 | 간질 조직, 혈관 생성 및 침윤 관련 특징 |

여기서 중요한 점은 CMS는 단순히 특정 유전자 변이 하나로 결정하는 것이 아니라 여러 유전자의 발현 패턴을 종합해 분류한다는 것이다.

## 6. 우리 프로젝트에 어떻게 적용할까?

우리 프로젝트에서는 다음과 같은 흐름으로 활용할 수 있다.

1. 제공된 데이터에서 유전자 변이 정보를 확보한다.
2. 유전자 및 분자 경로의 특징을 분석한다.
3. 기존 연구에서 제시한 암 아형 분류 기준을 참고한다.
4. 유전자 변이 패턴을 바탕으로 암종별 특성을 분석하고 SUBCLASS를 예측한다.
5. 예측 결과와 변이 특성을 바탕으로 치료 관련 정보를 탐색한다.

### 주의사항: 우리 데이터의 한계

본 대회에서 제공하는 데이터는 환자의 유전자 변이 정보 중심으로 구성되어 있으며, 유전자 발현량(Gene Expression), 복제수 변이(CNV), 단백질 발현 정보는 포함되어 있지 않다.

따라서 유전자 발현 패턴을 기반으로 암 아형을 분류하는 PAM50(유방암 분자 아형 분류)이나 CMS(대장암 분자 아형 분류)와 같은 방법을 제공된 데이터만으로 직접 수행하는 데 한계가 있다.

본 프로젝트에서는 제공된 유전자 변이 정보를 활용하여 암종별 유전적 특성과 변이 패턴을 학습하고, 이를 기반으로 SUBCLASS를 예측하는 방향으로 접근해야 한다.
