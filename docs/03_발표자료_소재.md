# 발표 자료(PPT) 소재 모음

정리: 김지연 (2026-11-09)  
팀 대화와 팀원 피드백에서 "발표에 쓰면 좋겠다"고 나온 내용을 PPT 흐름대로 모은 문서입니다. 각 항목의 자세한 근거는 괄호 안 문서를 봅니다.

> 숫자는 모두 **train 기준** 또는 **데이콘 리더보드(test 전체)** 기준입니다. test를 직접 들여다본 숫자는 쓰지 않습니다 ([00_데이터누수_규칙.md](./00_데이터누수_규칙.md)).

---

## 1. 문제 정의 · 배경

- **같은 변이라도 암 종류에 따라 치료가 다르다** → "변이만이 아니라 암 종류를 아는 것이 맞춤치료의 출발점"
  - 예: BRAF V600E가 흑색종·갑상선암에서는 BRAF 억제제, 대장암은 다른 요법 ([4_1](./4_1_맞춤치료_타깃변이_김지연.md), [4_2](./4_2_맞춤치료_표적치료근거_김도엽.md))
- **원발부위불명암(CUP)**: 악성 상피성 종양의 약 3~5% (Lancet 2012) → 26개 라벨이 "어느 장기의 암인지"라서 가장 잘 맞는 쓰임 ([5_0](./5_0_시장사용자_종합.md), [5_4](./5_4_시장사용자_규제연계_박종부.md))
- **우리 26개 라벨은 "어느 장기의 암인지"다**: TCGA 암종 코드라서, 유방암 Luminal A·B나 대장암 CMS처럼 같은 암 안을 다시 나누는 "분자 아형"과는 다름 ([1_1](./1_1_NGS_암아형_배경_김새봄.md) 4.2.1)
- **Macro F1은 작은 아형이 중요**: BRCA(786명)와 DLBC(38명)가 똑같은 비중(1/26) → 작은 아형 하나를 올리는 게 점수에 가장 효과적 (박종부 정리)

## 2. 데이터 이해 (train만 사용)

- 유전자 4,384개, 학습 환자 6,201명, 26개 아형 (대회 설명의 "6,199개"는 쓰지 않음, [5_4](./5_4_시장사용자_규제연계_박종부.md) 2-1)
- 환자 1명당 기능 변이가 있는 유전자는 **중앙값 10개** (silent 제외, 아형별 평균 약 3~108개) → "4,000개 변이"가 아니라 아주 희소한 데이터 ([5_0](./5_0_시장사용자_종합.md), [5_4](./5_4_시장사용자_규제연계_박종부.md) 2-5)
- **26개 라벨을 서로 완전히 독립된 암으로 보면 안 된다**: GBMLGG(=GBM+LGG), KIPAN(=KICH+KIRC+KIRP), STES(=위+식도)처럼 여러 암을 합친 묶음 라벨이 있고, KIRC·LGG는 묶음 안에 들어가는데도 따로 라벨이 있음 ([1_1](./1_1_NGS_암아형_배경_김새봄.md) 4.2.4)
- **겹치는 라벨**: KIRC의 81%, LGG의 76%가 각각 KIPAN·GBMLGG 환자와 변이가 완전히 같음 → 이 환자들의 정확도 0.19, 어떤 모델도 둘 다 맞힐 수 없음 (김도엽 분석, [5_4](./5_4_시장사용자_규제연계_박종부.md) 2-7)
- 한 칸에 변이가 여러 개(`E726K H1047R`) → 공백으로 나눠서 처리함 (박종부 확인)

## 3. 모델링 과정 · 실험 (스토리로 쓰기 좋음)

- **핫스팟 피처**: "BRAF 600번", "IDH1 132번"처럼 유전자 안에서 자주 바뀌는 자리 → 리더보드 **+0.014**, 팀 최고 점수의 핵심 ([2_0](./2_0_유전자경로_종합.md))
- **파생변수 6개 실험**: 하나씩 넣어서 CV로 비교 ([2_0](./2_0_유전자경로_종합.md) 6절)
  - 효과 있음: 변이 종류(silent·nonsense·frameshift), 끊김 표시
  - 효과 없음: 경로, 드라이버, 아형 마커
  - **"드라이버 정보를 넣으니 오히려 떨어졌다"** 는 Jiao 2020 논문과 같은 결과를 우리 데이터로 재현 ([6_1](./6_1_규제윤리_박종부.md) 4-2)
- **CV와 리더보드가 반대로 움직임**
  - CV가 높은 모델일수록 리더보드는 낮았음 (김도엽 v1 CV 0.44 → 리더보드 0.30, v2-N5 CV 0.41 → 리더보드 0.32)
  - 해석: "있다/없다" 정보(핫스팟)는 test에서도 통하지만 "개수·비율" 정보는 안 통함 → **단순하고 굵은 피처가 더 일반화가 잘 됨**
  - 리더보드가 test 100%라 우연이 아님을 train 시뮬레이션으로 확인 (표본 흔들림 ±0.02, 아형 비율 차이만으로는 설명 안 됨)
- **누수 방지를 철저히 지킴**: fold 안에서만 기준을 만들고, test는 값 세기도 하지 않음 ([00](./00_데이터누수_규칙.md)) → 감점 요소 방어

## 4. 결과

- 리더보드 기록: 베이스라인 0.3097 → v2-N5 **0.3236** (팀 최고, 11/9 기준 7팀 중 5등) → 최종 점수로 갱신
- 성능을 말할 때는 **CV가 아니라 리더보드 점수(test 기준)** 를 씀. Top-3 66.8%를 쓸 때는 "train 교차검증 기준, 실제는 더 낮을 수 있음"을 같이 표시 ([5_0](./5_0_시장사용자_종합.md))
- 추론 속도: 환자 1명 **0.15초** → "1초 안에" ([5_3](./5_3_시장사용자_보완_김지연.md))

## 5. 모델 해석 ([3_3](./3_3_모델_중요피처_혼동행렬.md))

- **모델이 많이 참고한 변이 = 실제 표적치료 타깃**: IDH1_132(3위), BRAF_600(5위), PIK3CA(8위) → "AI 판단이 생물학적으로도 말이 된다"
- 교과서적 조합이 상위권: VHL(신장암), APC(대장암), PTEN(자궁내막암), NPM1(백혈병)
- 혼동 행렬: 겹치는 라벨이 오답 1~3위, 그다음은 변이가 적은 암끼리(PRAD·THCA → PCPG)
- ⚠️ ACC 전용 패턴(LRIG1, SOWAHC silent 변이)은 원인 유전자처럼 소개하지 않음

## 6. 맞춤치료 연결 ([4_0](./4_0_맞춤치료_종합.md), [4_2](./4_2_맞춤치료_표적치료근거_김도엽.md))

- 서비스 흐름: 변이 목록 → **암 종류 Top-3 + 근거 유전자** → 치료 타깃 변이 "참고 정보" → 의사가 결정
- "핫스팟 ≠ 정확한 변이": 분류에는 위치 단위(BRAF 600번), 치료 근거에는 정확한 변이(V600E)가 필요 ([4_2](./4_2_맞춤치료_표적치료근거_김도엽.md) 2.3)
- 우리 데이터로 확인할 수 없는 것: 유전자 융합, 증폭(HER2), MSI, KRAS ([4_2](./4_2_맞춤치료_표적치료근거_김도엽.md) 4절) → 한계 슬라이드에 그대로

## 7. 시장 · 사용자 ([5_0](./5_0_시장사용자_종합.md), [5_4](./5_4_시장사용자_규제연계_박종부.md))

- NGS 패널 검사 2017 → 2021 **5.4배**, 대한암학회 회원 **89.5%가 NGS 필수**
- 차별점: 온코크로스는 RNA(전사체) 기반이라 별도 검사 필요 → **우리는 이미 한 NGS 변이 목록만 씀**
- 1차 고객: 유전체 분석 기관(B2B) → 규제상 가장 깔끔하고, 보험 수가가 아직 정비 중이라 현실적 ([5_4](./5_4_시장사용자_규제연계_박종부.md) 4절)

## 8. 규제 · 윤리 ([6_1](./6_1_규제윤리_박종부.md))

- 쓸 표현 / 쓰지 않을 표현: "진단·판정·의사 대체" ❌ → "예측 보조·후보 제시·의사결정 지원" ✅, "연구용 프로토타입(RUO)"
- 국내에 **AI 암 진단 보조 3등급 허가 선례**(딥바이오, 루닛) → 규제 경로가 열려 있음
- **"근거 유전자" 표시 = AI 기본법이 요구하는 결과 설명 방안** 에 대응하는 기능 (단, "원인 유전자가 아님" 주석)
- 유전정보는 민감정보 → 병원 내부 설치형 옵션, 처리위탁 구조

## 9. 한계 ([5_0](./5_0_시장사용자_종합.md) 6절, [6_1](./6_1_규제윤리_박종부.md) 8절)

- 겹치는 라벨 (KIRC 81%, LGG 76%)
- **변이 정보만 있어서 PAM50·CMS 같은 분자 아형 분류는 직접 할 수 없음**: 이 방법들은 유전자 발현량을 쓰는데, 우리 데이터에는 발현량·복제수 변이(CNV)·단백질 정보가 없음 ([1_1](./1_1_NGS_암아형_배경_김새봄.md) 6절)
- 학습 데이터가 서양인 중심일 가능성 (TCGA 유럽계 82.7%, 동아시아계 6.3%, Carrot-Zhang 2020 원문 확인) → 한국인 외부 검증 필요
- 변이가 하나도 없는 환자(silent 제외 121명)는 근거 없이 예측 → "판단 보류" 표시
- CV와 리더보드 차이 0.1 이상 → test 환자가 train과 다를 가능성
- 26개 라벨 밖 암, 전이암은 검증 안 됨 / 대회 데이터는 비영리 목적만
