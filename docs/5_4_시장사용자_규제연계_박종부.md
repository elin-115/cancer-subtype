## 2. 확인 중 발견한 사항

### 2-1. ✅ 유전자 수: 제공 데이터 기준 4,384개

- **출처**
  - 제공 데이터 `train.csv`, `test.csv` 직접 집계 (2026-11-09)
  - 데이콘 대회 페이지 — 대회 설명 "6,199개 유전자"
- **핵심 내용**

| 항목 | train | test |
|---|---|---|
| 환자(행) 수 | **6,201명** | 2,546명 |
| 유전자(열) 수 | **4,384개** | 4,384개 (train과 동일한 유전자 구성) |
| 그 외 열 | ID, SUBCLASS(정답) | ID |
| 암 아형 수 | **26개** | — |
| 한 번 이상 변이가 있는 유전자 | 4,230개 (154개는 전원 WT) | 4,358개 |
| 결측치 | 없음 | 없음 |

  - 팀 문서(5_0, 5_1, 5_2)의 **4,384개가 맞습니다.**
  - 대회 설명의 "6,199개"는 유전자 수와 맞지 않습니다. train 환자 수(6,201명)와 거의 같아 **환자 수를 잘못 적었거나 다른 버전 데이터 기준일 가능성**이 있으나, 데이터만으로는 확정할 수 없습니다.
- **우리 프로젝트 적용**
  - 발표에서는 대회 설명을 인용하지 말고 **"제공 데이터 기준 유전자 4,384개, 학습 환자 6,201명"**으로 씁니다.
  - "한 번 이상 변이가 있는 유전자 4,230개"는 특징 선택(전원 WT인 154개 제외) 논의에 참고할 수 있습니다. (모델 담당 공유)

### 2-2. ✅ CUP 비율의 기준

- **출처**
  - Pavlidis N, Pentheroudakis G. Cancer of unknown primary site. *Lancet* 2012;379(9824):1428–35. — [DOI](https://doi.org/10.1016/S0140-6736(11)61178-1), [초록 확인 링크](https://olympias.lib.uoi.gr/jspui/handle/123456789/23324?mode=full)
  - Pavlidis N, Fizazi K. Cancer of unknown primary (CUP). *Crit Rev Oncol Hematol* 2005 — [초록 확인 링크](https://olympias2.lib.uoi.gr/items/855f66f6-6231-462f-a360-95c40ee0e9cb/full)
- **핵심 내용**
  - Lancet 2012 초록은 CUP를 **모든 악성 상피성 종양의 3~5%**로 설명합니다. → 5_3의 표현이 정확합니다.
  - 같은 저자의 2005년 리뷰는 **모든 인간 악성종양의 3~5%**로 표현해, 문헌마다 분모가 다르게 쓰입니다.
- **우리 프로젝트 적용**
  - 발표에서는 **Lancet 2012 기준 하나로 통일**합니다: "CUP는 악성 상피성 종양의 약 3~5%"
  - 국내 CUP 환자 수는 아직 확인하지 못했습니다(5절 참고).

### 2-3. 온코크로스 온코파인드AI 상태 변경

- **출처**
  - 시그널 이브닝 뉴스 요약(2025-04-02), "온코크로스, 원발부위불명암 진단 플랫폼 온코파인드AI 개발 완료" — [링크](https://files-scs.pstatic.net/2025/04/02/2gOxOqwYYE/250402(수)%20Signal%20evening.pdf)
  - 딜사이트, 온코크로스 코스닥 재도전 — [링크](https://dealsite.co.kr/articles/132666)
- **핵심 내용**
  - 5_0은 온코파인드를 "개발 단계"로 적었으나, 2025년 4월 **개발 완료** 보도가 있습니다.
  - 온코파인드AI는 **RNA-Seq(전사체) 데이터**로 암 조직의 유전자 발현 정보를 분석하는 방식입니다.
- **우리 프로젝트 적용**
  - 경쟁 비교에서 "온코크로스도 원발 부위 AI 보유(전사체 기반, 회사 측 발표)"로 고칩니다.
  - **차별점이 선명해집니다:** 온코파인드는 별도 전사체 검사가 필요하지만, 우리 도구는 **이미 시행한 NGS 패널의 변이 목록만** 씁니다. 5_3의 "환자 부담 80% 상향 → 추가 검사 없이 기존 결과를 해석" 논리와 이어집니다.
  - 단, 회사 측 성능 주장은 검증된 수치가 아니므로 성능 비교는 하지 않습니다.

### 2-5. ⚠️ 환자당 변이 유전자 수

- **출처:** 제공 데이터 `train.csv` 직접 집계 (2026-11-09)
- **핵심 내용**
  - 5_0 §5는 "실제 변이는 아형마다 평균 3~180개"로 적었으나, 집계 결과 아형별 평균은 **3.1개(LAML) ~ 134.0개(UCEC)**입니다.

| 구분 | 값 |
|---|---|
| 환자 1명당 변이 유전자 수 | 중앙값 **14개**, 평균 35.3개, 최소 0개, 최대 2,393개 |
| 변이가 하나도 없는 환자 | 94명 |
| 변이 유전자가 500개 이상인 환자 | 37명 |
| 아형별 평균이 가장 낮은 아형 | LAML 3.1 / THCA 4.2 / THYM 4.4 / PCPG 4.4 |
| 아형별 평균이 가장 높은 아형 | UCEC 134.0 / SKCM 132.5 / STES 81.8 / COAD 73.1 |

  - UCEC는 평균 134.0개지만 중앙값은 18개로, **일부 환자의 변이가 매우 많아 평균을 끌어올리는** 구조입니다(COAD도 비슷함).
- **우리 프로젝트 적용**
  - 발표 표현을 **"유전자 4,384개를 검사하고, 환자 1명당 실제 변이 유전자는 중앙값 14개(아형별 평균 3~134개)"**로 고치는 것을 제안합니다.
  - 변이가 0개인 환자 94명은 모델이 근거 없이 답할 수밖에 없는 경우이므로, 6_1 4-2의 "판단 보류" 표시가 필요한 사례입니다.

### 3-2. 5_0 §4 출력 — "근거 유전자"

- **출처:** 6_1 3-2절 (AI 기본법 제34조 고영향 AI 책무)
- **핵심 내용:** 고영향 AI 사업자는 **최종 결과 도출에 사용된 주요 기준과 학습데이터 개요에 대한 설명 방안**을 마련해야 합니다.

  - **주의 문구 필요:** 근거 유전자는 "모델이 많이 참고한 유전자"이지 "그 암의 원인 유전자"가 아닙니다.

| 2023 | 디지털·AI 혁신의료기술은 최대 3년 건보 **임시등재**, 신청 시 비급여 또는 선별급여 선택 가능 |
| 첫 사례 | 제이엘케이 뇌졸중 진단 보조 AI가 AI 분야 첫 건보 편입 사례였으나, 평가 완료 시까지 **비급여**로 분류 |
| 2026.1 | 국제 수준 임상평가를 거친 의료기기는 신의료기술평가 없이 진입하는 **시장 즉시진입 제도** 시행 |
| 2026.2 | 심평원장, 의료 AI 활용 진료수가 신설은 **시기상조**라는 입장 |
| 2026.7 | AI 급여 적정성 평가 연구 진행. 한 환자에게 여러 AI를 써도 **주된 1개 AI 분석료만 인정**하는 안 등에 업계·학계 우려 |

- **우리 프로젝트 적용**
  - 진단 보조 AI는 당분간 **비급여**일 가능성이 높고, 보험 수가에 기대는 수익 모델은 불확실합니다.
  - 따라서 병원 대상 건당 과금보다 **유전체 분석 기관(B2B)에 해석 모듈로 공급**하는 모델이 현실적입니다. (3-1의 규제 결론과 같은 방향)
  - 발표 표현 예: "국내 수가 체계가 아직 정비 중이므로, 1차 고객은 NGS 검사를 수행하는 유전체 분석 기관으로 설정했습니다."
