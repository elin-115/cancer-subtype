## 1. 3분 요약

1. **같은 변이라도 암 종류가 다르면 약이 다릅니다.** BRAF V600E는 피부암·갑상선암에서는 BRAF 억제제를 쓰지만, 대장암에서는 다른 조합을 씁니다. 그래서 "어느 암인지"를 맞히는 우리 모델이 맞춤치료의 **앞 단계**입니다.
2. **같은 유전자라도 "어디가 어떻게" 바뀌었는지가 중요합니다.** BRAF 600번 자리 변이 339명 중 허가 약이 있는 V600E는 321명입니다. 나머지 18명은 같은 유전자지만 허가 대상이 아닙니다.
3. **우리 데이터에서 치료 타깃이 많이 보이는 변이는 3개**입니다: BRAF V600E(321명), IDH1 R132H(345명), PIK3CA 3종(약 370명). 우리 모델도 이 유전자들을 가장 중요하게 봤습니다(IDH1 2위·BRAF 3위·PIK3CA 4위).
4. **변이만으로 약을 정할 수는 없습니다.** 병기, 이전 치료, 조직형, 수용체 상태, 승인된 검사 결과가 있어야 합니다. 우리 데이터에는 이 정보가 없어서, 서비스에서는 "치료 추천"이 아니라 **"알려진 근거 + 더 확인할 것"**을 보여줍니다.
5. **우리가 하려는 일(변이 → 원발 암종 후보)은 이미 임상에서 검증 중입니다.** 2023년 Nature Medicine의 OncoNPC 모델은 같은 입력으로 원발 부위를 맞히고, 예측에 맞춰 치료받은 원발부위불명암 환자의 생존이 더 길었습니다(HR 0.35). 2024년 ESMO는 원발부위불명암을 **NGS 검사 권고 대상**에 새로 넣었습니다.

## 2. 용어 사전 (쉽게)

| 용어 | 쉽게 말하면 |
|---|---|
| 맞춤치료(정밀의료) | 환자의 유전자 변이에 맞춰 치료를 고르는 것 |
| 표적치료제 | 특정 변이가 있는 암세포만 골라 공격하도록 만든 약 |
| 변이 표기 읽는 법 | `V600E` = 단백질 **600번째** 아미노산이 V(발린)에서 E(글루탐산)로 바뀜. `R132H`도 같은 방식. `*`는 단백질이 중간에 끊김(nonsense), `fs`는 틀이 어긋남(frameshift) |
| 핫스팟 | 여러 환자에서 반복해서 변이가 생기는 "자리". 예: BRAF 600번, IDH1 132번 |
| 정확한 변이 vs 위치 | `BRAF 600번`은 자리, `V600E`는 정확한 변이. **약 허가는 대부분 정확한 변이 기준** |
| 암종 불문(tumor-agnostic) 승인 | 암이 어느 장기에서 생겼는지와 상관없이, 변이만 있으면 쓸 수 있게 허가된 것 |
| 동반진단(CDx) | 약을 쓰기 전에 변이를 확인하도록 허가된 검사. 허가 문구에 "승인된 검사로 확인된" 조건이 붙음 |
| 가속 승인 / 정식 승인 | 미국 FDA의 임시 승인(초기 임상 근거) / 확정 승인(3상 등 추가 근거). 2024년 가속 → 2026년 정식으로 바뀐 약이 여럿 있음 |
| 급여 | 건강보험이 약값을 일부 부담하는 것. 허가가 나도 급여가 안 되면 환자가 전액 부담(비급여) |
| TMB / MSI | 변이 부담 / 현미부수체 불안정성. 면역항암제 사용 기준. 우리 데이터로는 공식 계산 불가 |
| CUP(원발부위불명암) | 암이 퍼진 곳은 찾았는데 처음 생긴 장기를 모르는 경우. 우리 모델의 대표 사용 장면(⑤) |
| 분자종양위원회(MTB) | 여러 과 의사가 모여 변이 결과를 보고 치료를 논의하는 회의 |

## 3. 왜 "암 종류"를 알아야 하나 — BRAF V600E 이야기

train에 BRAF V600E 변이가 있는 환자가 321명 있습니다. 갑상선암(THCA) 184명, 피부암(SKCM) 106명, 대장암(COAD) 20명이 같은 변이를 갖고 있습니다. 그런데 치료는 다릅니다.

| 환자 | 같은 변이 | 치료(미국 FDA 기준) |
|---|---|---|
| 피부암(흑색종) 환자 | BRAF V600E | BRAF 억제제 + MEK 억제제(dabrafenib + trametinib) |
| 갑상선암 환자 | BRAF V600E | 역형성 갑상선암이면 같은 조합 허가. 보통 갑상선암(분화암)은 조건이 다름 |
| 대장암 환자 | BRAF V600E | 위 조합은 **대장암 제외**. 대신 encorafenib + cetuximab + 화학요법(2026-02-24 정식 승인, 생존기간 30.3 vs 15.1개월) |

왜 대장암만 다를까요? 대장암 세포는 BRAF를 막으면 다른 길(EGFR)로 다시 신호를 보내서 BRAF 억제제 하나로는 잘 듣지 않습니다. 그래서 EGFR을 함께 막는 세툭시맙을 더합니다.

> **우리 모델과의 연결**: 변이 목록만 보고 "어느 암인지" 후보를 내는 것이 우리 모델입니다. 그 다음에야 "이 암이면 이 약"이라는 판단이 시작됩니다. 모델이 틀리면 치료 선택도 틀어질 수 있으니, 모델은 **후보 제시**까지만 하고 확정은 의사가 합니다.

## 4. train에서 찾은 치료 타깃 변이

환자 수는 train 6,201명 기준입니다. 셀을 공백으로 나눈 뒤 **토큰이 정확히 일치하는 행**을 셌습니다(한 행에 중복 표기돼도 1). test는 보지 않았습니다. 표기 빈도일 뿐 독립 환자 수·병원성 판정이 아닙니다. 전체 27개 변이는 [4_3 표](./4_3_치료타깃변이_train집계.md).

### 4.1 환자가 많고 약이 분명한 변이 (발표의 중심)

|---|---:|---|---|---|---|

## 5. 변이별 "약을 쓰려면 무엇이 더 필요한가"

표적치료제 허가 문구에는 변이 외에도 조건이 붙습니다. 우리 데이터에는 이 조건 정보가 하나도 없습니다. 자세한 허가 문구·출처는 [4_2](./4_2_맞춤치료_표적치료근거_김도엽.md) 3절.

| 변이 | 허가에 붙는 조건 | 우리 데이터에 없는 것 |
|---|---|---|
| BRAF V600E | 암종(CRC 제외), 6세↑, 이전 치료 후 진행, 승인 검사 / CRC는 별도 병용 | THCA가 역형성인지, SKCM 병기, COAD 치료 이력 |
| IDH1/IDH2 (신경교종) | **2등급** 성상세포종·희돌기교종, 수술 후, 12세↑ | GBMLGG/LGG 라벨은 등급·조직형을 알려주지 않음 |
| IDH1/IDH2 (AML) | 신규/재발 여부, 연령, 승인 검사 | LAML 라벨만 있음 |
| PIK3CA | **HR+/HER2−** 유방암, 내분비 요법 이력 | 수용체 상태 전부 없음 |
| EGFR L858R | 비소세포폐암, 병기, 치료 단계 | LUAD 라벨만 있음 |
| FGFR3 S249C | 요로상피암, 이전 전신치료, 동반진단 | BLCA 라벨만 있음 |
| ERBB2 | HER2 IHC 3+ 또는 증폭 | 발현·증폭 정보 없음 |
| RET / NTRK | 수질성 갑상선암 여부, **융합(fusion) 여부** | 융합은 데이터로 판정 불가 |
| BRCA1/2 | 병원성 판정, 생식세포/체세포, 암종, 치료 단계 | 표기만 있음 |
| TMB-H / MSI-H | 승인 검사 결과(≥10 mut/Mb, MSI-H/dMMR) | TMB 공식 계산 불가, MSI 검사 없음 |

| 이토베비(inavolisib) — PIK3CA 유방암 | 2025-07-29 허가 → 2026-04 빅3 병원 처방 진입. **급여 미확인** | 메디포뉴스 2025-07, 데일리팜 2026-04 |
| 레테브모(selpercatinib) — RET | 2026-10-01 급여 확대(건정심). 세부 적응증 미확인 | 메디포뉴스 2026-10 |
| NGS 패널 검사 | 2024년부터 대장암 등 대부분 고형암 본인부담 50% → **80%**(폐암 외). 임상의: "BRAF 검사를 해야 비라토비를 쓸 수 있는데 검사비가 장벽" | 메디게이트뉴스 2024-01-11, [5_0](./5_0_시장사용자_종합.md) |

> **시사점**: 미국에서 암종 불문 승인이 있어도 국내에서는 암종별로 허가·급여가 따로 움직이고, 급여가 돼도 암종 제한(NCCN 2A)이 붙습니다. 서비스 화면에 치료 정보를 보여준다면 **관할권(US/KR)과 급여 여부를 반드시 구분**합니다.

## 7. 우리 모델이 본 유전자와 치료 타깃이 겹치는가 (실측)

4_1의 확인 항목 "모델이 중요하게 본 유전자와 치료 타깃이 겹치는지"를 김도엽 v1 결과로 확인했습니다(train 5-Fold, 유전자 단위).

| 유전자 | XGBoost \|SHAP\| 순위 | LR \|계수\| 순위 | 치료 타깃? |
|---|---:|---:|---|
| TP53 | 1 | 1 | 직접 표적치료제 없음 |
| **IDH1** | 2 | 4 | ✅ vorasidenib / ivosidenib |
| **BRAF** | 3 | 7 | ✅ BRAF+MEK 억제제 (Permutation 중요도 1위, −0.046) |
| **PIK3CA** | 4 | 2 | ✅ alpelisib / inavolisib |
| CTNNB1 | 5 | 6 | 연구 단계 |
| NPM1 | 6 | 36 | AML 분류 마커 |
| **IDH2** | 7 | 21 | ✅ enasidenib |
| VHL | 8 | 5 | 신장암 핵심 유전자(belzutifan은 VHL병·신장암 허가) |
| PTEN | 16 | 3 | capivasertib 대상 변이 중 하나 |
| EGFR | 23 | 8 | ✅ (단, train의 EGFR 변이 대부분은 L858R이 아님) |
| FGFR3 / RET / BRCA1 / BRCA2 / ERBB2 | 116 / 82 / 121 / 579 / 1041 | 116 / 120 / 521 / 243 / 74 | 타깃이지만 train에 드물어 모델 기여 작음 |

변이 토큰 단위 LR 계수 상위: **BRAF=V600E(1위), IDH1=R132H(2위)**, TP53=R248Q, IDH1=R132C, HRAS=Q61R, PIK3CA=H1047R·E542K·E545K, IDH2=R172K.

**해석**
- "모델이 중요하게 본 유전자 상위 7개 중 4개(IDH1·BRAF·PIK3CA·IDH2)는 표적치료제가 있는 유전자"라는 문장은 실측으로 뒷받침됩니다.
- 하지만 TP53·CTNNB1처럼 모델에는 중요한데 약이 없는 유전자도 있고, FGFR3·RET·BRCA1/2처럼 약은 있는데 train에 드물어 모델이 거의 안 쓰는 유전자도 있습니다. → **"모델 중요도 = 치료 중요도"가 아니라고** 발표에서 같이 말합니다.
- 중요도는 예측에 얼마나 기여했는지일 뿐, 원인이나 임상 바이오마커 판정이 아닙니다.

## 8. 변이가 있으면 실제로 치료로 이어지나 — 대규모 연구 숫자

"NGS 검사를 하면 맞춤치료를 받는다"는 기대와 현실의 차이를 숫자로 보여주는 연구들입니다. 발표에서 기대치를 낮추고 우리 도구의 자리를 설명할 때 씁니다.

| 연구 | 규모 | 결과 | 우리 발표에서의 의미 |
|---|---|---|---|
| **MSK-IMPACT** (Zehir 2017, Nat Med) | 전이암 10,336명, 미국 | 실행 가능한 변이 보유 **37%**, 변이에 맞는 임상시험 참여 **11%** | 변이가 있어도 치료로 이어지는 비율은 제한적 |
| **NCI-MATCH** (Flaherty 2020, JCO) | 불응성 암 5,954명 선별, 미국 | 실행 가능한 변이 **37.6%**, 치료군 배정 **17.8%**. 내성 관련 동반 변이 71% | 변이 하나만 보면 안 되고 동반 변이도 중요 |
| **K-MASTER 대장암** (Lee 2021, Cancer Res Treat) | 전이성 대장암 994명, **한국** | 현재 치료 선택지가 있는 변이 **53.7%**(BRAF V600E 4.7%, MSI-H 1.5%, HER2 증폭 1.0% 포함), 임상시험 후보 29.6% | 국내 환자 데이터 기준 수치. KRAS 43.6%, TP53 43.1%, PIK3CA 12.7% |
| **CUPISCO** (Krämer 2024, Lancet) | 원발부위불명암 436명 무작위, 34개국 | 유전체 검사 기반 맞춤치료가 항암화학요법보다 무진행 생존 연장: **6.1 vs 4.4개월**(HR 0.72). 실행 가능 변이가 있으면 8.1 vs 4.7개월 | CUP에서 변이 기반 치료가 효과 있다는 3상급 근거 |
| **OncoNPC** (Moon 2023, Nat Med) | 원발 알려진 종양 36,445개로 학습, 22개 암종, CUP 971명 검증 | 패널 변이 데이터로 원발 부위 예측(전체 정확도 약 80%, 고신뢰 65%는 95%). **예측 원발에 맞춰 치료받은 CUP 환자 생존 HR 0.35**. 표적치료 매칭 가능 환자 12.7% → 27.8%(2.2배) | **우리 과제와 같은 문제**. 암종 예측이 치료 선택을 바꿀 수 있다는 근거(단, 후향 연구) |
| **ESMO NGS 권고 2024** (Mosele 2024, Ann Oncol) | 유럽 종양학회 권고 | NGS 권고 암종에 유방암·GIST·육종·갑상선암·**원발부위불명암** 추가. NTRK·MSI·RET·BRAF V600E·TMB 등 암종 불문 변이는 "매칭 치료 접근 가능 시" 검사 권고 | 우리 입력(NGS 변이)과 사용 장면(CUP)이 국제 권고와 맞음 |

> **쉽게 말하면**: 검사를 받은 환자 셋 중 하나 정도에서 "약이 있는 변이"가 나오고, 실제로 그 약을 받는 사람은 열 중 하나 남짓입니다. 그 틈을 줄이는 것이 분자종양위원회와 우리 같은 보조 도구의 역할입니다.

## 10. 근거를 등급으로 나누는 체계 (서비스 설계용)

> **쉽게 말하면**: 신호등처럼 "허가된 약(초록) / 가이드라인·임상 근거(노랑) / 연구 단계(빨강)"를 나누는 공식 체계들입니다. 우리 화면도 이 구분을 따라야 "연구 단계 약을 허가 약처럼" 보여주는 실수를 막을 수 있습니다.

| 체계 | 핵심 | 우리 적용 |
|---|---|---|
| **OncoKB 근거 수준** (Chakravarty 2017) | Level 1 FDA 인정 바이오마커 · 2 표준 진료 · 3A/3B 임상 근거 · 4 생물학적 근거 · R1/R2 내성 | 화면에서 "허가 / 가이드라인 / 임상시험 / 전임상"을 나누는 틀로 참고. **DB 다운로드는 외부 데이터라 사용하지 않음** |
| **AMP/ASCO/CAP 2017** (Li 2017) | Tier I 강한 임상적 중요성 · II 잠재적 · III 불명확(VUS) · IV 양성 | 변이 문자열만으로 Tier를 자동 부여하지 않음 |
| **ESMO ESCAT v1 → v2** (Mateo 2018 → El Helali 2026, 2026-10-22 공개) | v2: Tier I·II를 근거 확실성에 따라 세분, Tier X를 X-A(예측력 없음)/X-B(약 비활성)로 구분, 암종 불문 근거 기준(ETAC-S), **내성 바이오마커 4단계** 신설 | 변이–치료 연결의 최신 기준. 등급 지정은 전문가 검토 필요 |

**우리 원칙**
1. 허가는 관할권·날짜·적응증·검사 조건을 함께 적는다.
2. 허가 / 가이드라인 / 임상시험 / 전임상을 구분한다.
3. 정확한 변이 수준 근거가 없으면 유전자 수준 근거를 특정 변이로 확대 적용하지 않는다.
4. 근거가 없으면 "확인되지 않음"으로 표시하고 추정하지 않는다.

## 11. 서비스에 어떻게 연결할지

⑤의 CUP 시나리오([5_0](./5_0_시장사용자_종합.md) 4절) 다음 단계입니다. OncoNPC(8절)가 보여준 흐름과 같습니다.

```
① NGS 변이 목록 입력
   ↓
② 우리 모델: 암종 후보 Top-3 + 확률 (예: SKCM 0.61 / THCA 0.22 / COAD 0.08)
   ↓
③ 참고 정보: 이 환자의 변이 중 "치료 타깃으로 알려진 정확한 변이"를
   [변이] [후보 암종별 허가·근거] [관할권(US/KR)·급여] [판단에 더 필요한 정보] 로 표시
   ↓
④ 의사: 암종을 확정하고, 치료는 의사가 결정 (우리는 추천하지 않음)
```

**③ 화면 예시 (BRAF V600E가 있는 환자)**

| 항목 | 표시 내용 |
|---|---|
| 변이 | BRAF V600E (정확한 변이 일치) |
| 후보 암종별 근거 | SKCM: BRAF+MEK 억제제 — US FDA 허가, KR 허가·급여 / THCA: 역형성 갑상선암이면 US 허가 / COAD: 암종 불문 승인 **제외**, encorafenib 기반 병용은 US 2026 정식 승인·KR 2차 급여(2024) |
| 더 확인할 것 | 조직형, 병기, 이전 치료, 승인된 검사 결과 |
| 근거 등급 | 허가(규제기관) — 출처 링크, 확인일 2026-11-09 |

**MVP 우선 사례**: BRAF V600E, IDH1 R132H/R132C, IDH2 R140Q·R172K, PIK3CA H1047R/E545K/E542K, EGFR L858R, FGFR3 S249C — train에 실제로 있고 허가 근거가 분명한 변이.

**한 레코드에 넣을 필드**([4_2](./4_2_맞춤치료_표적치료근거_김도엽.md) 6절): 변이·유전자 / 암종·조직형 / 치료제·병용 / 관할권 / 허가 상태·허가일 / 적응증·치료 단계·제외 조건 / 동반진단 / 근거 등급 체계 / 출처 URL·확인일 / 추가 필요 임상정보 / 전문가 검토 상태.

**조심할 것**
- ③은 **치료 추천이 아니라 참고 정보**입니다. "이 약을 쓰세요"라고 하면 의료기기 규제(⑥)에 걸립니다.
- 치료 타깃 목록은 **서비스 화면용**입니다. 운영진 답변(11/9, A-2)에 따라 논문의 핫스팟·드라이버 **유전자 이름 목록**은 피처로 쓸 수 있지만, 이 문서의 "변이 → 약 → 암종" 매핑처럼 **암종별 정보가 담긴 표는 피처로 쓰지 않습니다**([00_데이터누수_규칙.md](./00_데이터누수_규칙.md) 8절).
- 외부 치료 정보로 모델 예측값을 보정하거나 Test 예측을 바꾸지 않습니다.

## 12. 발표에서 쓸 표현 / 쓰지 않을 표현

**쓸 문장**
- "같은 BRAF V600E라도 피부암·갑상선암과 대장암은 치료가 다릅니다. 미국 FDA의 암종 불문 승인도 대장암은 제외했고, 대장암은 2026년에 별도 병용요법으로 승인됐습니다. 그래서 **암 종류를 아는 것이 맞춤치료의 출발점**입니다."
- "우리 모델이 가장 중요하게 본 유전자 상위 7개 중 **IDH1, BRAF, PIK3CA, IDH2 네 개는 실제로 표적치료제가 있는 유전자**입니다."
- "변이 유전자가 아니라 **정확한 변이**가 중요합니다. BRAF 600번 변이 339명 중 허가 대상인 V600E는 321명입니다."
- "같은 문제를 푼 OncoNPC(2023, Nature Medicine)에서는 예측한 원발 부위에 맞춰 치료받은 환자의 생존이 더 길었습니다. 2024년 ESMO는 원발부위불명암을 NGS 권고 대상에 넣었습니다."
- "다만 우리 데이터에는 KRAS, 유전자 융합, 증폭, MSI, 병기 정보가 없어 치료 정보 제공에는 한계가 있고, 국내 허가·급여는 미국과 다릅니다."
- "대규모 임상 시퀀싱에서도 약이 있는 변이를 가진 환자는 약 37%, 실제 맞춤 임상시험에 들어간 환자는 11%였습니다."

| 쓰지 않음 | 대신 이렇게 |
|---|---|
| 치료 추천, 약 처방 제안 | 치료 **참고 정보**, 허가·근거 표시 |
| "BRAF 변이 환자 339명에게 표적치료 가능" | "V600E 321명 중 암종·조건에 따라 허가 범위가 다름" |

## 13. 한계 (발표 때 같이 말하기)

- 미국 FDA 허가 중심으로 정리했고, 국내 허가·급여는 약물별로 일부만 확인했습니다(6절). 나머지는 "미확인"으로 남겼습니다.
- SUBCLASS는 대회용 암종 라벨이라 조직형·병기·등급·수용체 상태가 없습니다. GBMLGG/LGG, KIPAN/KIRC처럼 포함 관계인 라벨도 있습니다.
- train 빈도는 표본 구성의 결과이지, 유병률이나 치료 적합 환자 비율이 아닙니다.
- OncoNPC·CUPISCO는 다른 데이터·다른 패널로 얻은 결과이며 우리 모델의 성능을 보증하지 않습니다.
- 약물 허가·급여·가이드라인은 계속 바뀝니다. 발표 직전에 날짜와 출처를 다시 확인합니다.
- 이번 결과는 해커톤 예측 연구이며 임상 진단·치료 결정 도구가 아닙니다.
