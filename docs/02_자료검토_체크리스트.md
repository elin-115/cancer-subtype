## ② 유전자·경로 지식 → 파생변수 (여은지)

파일: [2_1_유전자경로_파생변수_여은지.md](./2_1_유전자경로_파생변수_여은지.md)

- [x] 🔴 **자료 4 `subclass_specific_marker_score`**: 정답(SUBCLASS)을 보고 아형별 자주 나오는 유전자를 고르는 피처입니다. 규칙 위반은 아니지만 **CV fold 안에서 train 부분으로만** 골라야 CV 점수가 부풀려지지 않습니다. ([00_데이터누수_규칙.md](./00_데이터누수_규칙.md) 4번)
  - 결정:정답 라벨 기반 피처의 누수 위험을 원천 차단하기 위해, 무리한 파생변수 생성 대신 팀장님 모델링 방향에 맞춰 '2단계 계층적 분류 및 오답 분석'의 생물학적 근거로 안전하게 활용하기로 결정했습니다.
- [x] 🔴 **자료 3 OncoKB**: OncoKB 데이터베이스를 내려받아 쓰면 외부 데이터입니다. "동의 변이 걸러내기, 핫스팟 플래그" 아이디어만 쓰고, 기준은 train에서 직접 정합니다.
  - 결정:OncoKB 외부 DB를 직접 다운로드하여 매핑하지 않고, 논문에서 제시하는 "실제 단백질 기능을 바꾸는 유효 변이와 무해한 동의 돌연변이(Synonymous)를 구분하는 분석 아이디어"를 Train 데이터셋 자체에서 규칙 기반으로 적용하기로 결정했습니다.
- [x] 🔴 **자료 1 경로 유전자 목록**: 논문의 경로 유전자 이름을 코드에 적어 쓰는 것이 허용되는지 운영진께 문의했습니다. ([00_데이터누수_규칙.md](./00_데이터누수_규칙.md) 8번)
  - 확인(11/9): 운영진 답변 "유전자 이름 목록만 참고하는 것은 가능". 드라이버는 암종 구분 없는 전체 목록만 가능
  - 결정: 이름만 코드에 적어서 사용 (데이터에 있는 유전자만, 행 단위 계산). 논문의 유전자 이름 목록을 도메인 지식으로 활용하는 것이 최종 승인되었습니다.
- [x] 🟡 **변이 종류 보완**: "첫 글자와 끝 글자가 다르면 기능 변이"만 적혀 있습니다. `*`(nonsense, 단백질이 중간에 끊김)와 `fs`(frameshift)도 있고, 이 둘은 기능을 더 크게 망가뜨리는 변이입니다.
  - 확인(11/8): train에 nonsense(`*`) 13,451개, frameshift(`fs`) 9,911개 있음
  - 결정:변이 판별 로직을 즉시 보완하기로 결정했습니다. 단순 missense(첫 글자 ≠ 끝 글자)뿐만 아니라, 단백질 기능을 치명적으로 파괴하는 nonsense('*') 13,451개와 frameshift('fs') 9,911개를 반드시 핵심 기능 상실 변이(High Impact)로 포함하여 집계합니다.
- [x] 🟡 **한 칸에 변이 여러 개**: 공백으로 구분된 변이가 여러 개 들어 있는 칸이 약 2만 2천 개입니다. 칸 개수와 실제 변이 개수가 다릅니다.
  - 확인(11/8): train EDA로 약 2만 2천 칸 확인
  - 결정:단순 셀(Cell) 단위 카운팅 방식을 폐기하고, 실제 변이 단위로 분리 집계하기로 결정했습니다. 셀 내 값을 공백(' ')으로 split하여 각 환자의 4,384개 유전자에 존재하는 모든 개별 변이를 추출한 뒤, 실제 총 변이 수와 변이 유형별(동의/비동의/nonsense/fs) 필터링을 수행함으로써 약 2만 2천 개에 달하는 다중 변이 누락과 왜곡을 방지합니다.
- [x] 🟡 **자료 2 `patient_total_mutation_count`**: 베이스라인의 `n_mut`과 같은 피처입니다. "이미 있음"으로 표시합니다.
  - 확인(11/8): 베이스라인 `make_features`의 `n_mut`과 같은 계산
  - 결정:베이스라인 코드의 `n_mut`과 동일 피처임을 확인하였습니다.
- [x] 🟡 **차원 축약**: 경로 피처로 기존 4,384개 피처를 대체할지, 추가할지는 CV로 비교해서 정합니다.
  - 결정:5-Fold Stratified CV 실험을 통해 데이터 기반으로 결정하기로 했습니다. [1안: 기존 4,384개 유전자 피처 + 10대 경로 피처 추가(Concat)]와 [2안: 10대 경로 피처만으로 차원 축약(대체)]의 검증 성능(Macro F1)을 직접 비교 측정한 뒤, 과적합을 효과적으로 억제하면서 분류 점수가 가장 높은 최적의 조합을 최종 채택하기로 결정했습니다.
    - 차원 축약 1안 실험 결과: CV 0.414 -> 0.4094 하락하여 미채택

## ⑤ 시장성 조사 (여은지)

파일: [5_1_시장성조사_여은지.md](./5_1_시장성조사_여은지.md)

Grand View Research 원문과 숫자를 대조했습니다 (2026-11-08).
- ✅ 바이오마커 시장 269억 → 653억 달러 (2025→2033, CAGR 11.8%), 유전체 49.7%, 진단 58.5%, 북미 41.6%
- ✅ 암 유전체 진료 시장 181.2억 → 509.7억 달러 (2023→2030, CAGR 16.0%)

- [x] 🔴 **"NGS가 가장 빠른 성장률"**: 원문과 다릅니다. 원문에서 가장 빨리 성장하는 부문은 기술은 마이크로어레이(19.0%), 제품은 서비스(24.1%), 용도는 신약 개발(18.5%)입니다.
  - 확인(11/8): Grand View 원문 대조, 원문과 다름
  - 결정:원문 팩트를 엄밀하게 정정 반영하기로 결정했습니다. "NGS가 가장 빠른 성장률"이라는 오해의 소지가 있는 문구를 삭제하고, "NGS는 암 유전체 진료 시장의 약 절반을 차지하는 최대 지배적 기술 플랫폼이며, 세그먼트별 최고 성장률은 마이크로어레이(19.0%), 서비스(24.1%), 신약 개발(18.5%)이다"로 수치를 원문과 정확히 일치시켜 보고서에 수정 반영했습니다.
- [x] 🔴 **"환자 1명당 4,000개가 넘는 유전자 변이"**: 유전자 컬럼이 4,384개인 것이고, 대부분은 WT(변이 없음)입니다. 실제 변이 수는 아형마다 평균 약 3개(LAML)에서 180개(UCEC)입니다.
  - 확인(11/8): train EDA, 아형별 평균 약 3개(LAML)~180개(UCEC)
  - 결정:팀 통일 기준(5_0)에 맞춰 정정했습니다. 4,384개 유전자 패널 중 'silent 변이를 제외한 유전자 수 기준 환자당 중앙값 10개(아형별 평균 약 3~108개)' 수준으로 희소하게 나타난다는 팩트를 반영하여 보고서 표현을 수정 완료했습니다.
- [x] 🔴 **"확진", "정확히 확진"**: AI가 확진한다는 표현은 ⑥ 규제 쪽에서 문제가 됩니다. "진단 보조", "후보 제시"로 통일합니다.
  - 결정:식약처 및 FDA SaMD(의료기기 소프트웨어) 규제 가이드라인을 엄격히 준수하기로 결정했습니다. 의료법상 의사 고유의 권한인 "확진" 표현을 전면 삭제하고, "진단 보조(Clinical Decision Support)" 및 "암 아형 후보군(Top-3) 확률 제시"로 보고서 및 발표 자료 전반의 모든 용어를 일괄 수정 통일했습니다.
- [x] 🟡 **"68조와 88조의 교집합"**: 두 시장은 겹치는 부분이 있어서 이렇게 쓰면 규모가 실제보다 커 보일 수 있습니다. "두 시장에 걸쳐 있다" 정도로 바꿉니다.
  - 결정:시장 규모 과장 논란을 방지하기 위해 지적을 수용하여 순화하기로 결정했습니다. 단순 덧셈이나 교집합 대신 "두 시장의 영역에 걸쳐 있는 연관 타깃 시장(암 유전체 진료 약 69조 원 및 바이오마커 진단 약 88조 원)"으로 표현을 변경하여 수치의 객관성을 확보했습니다.
- [x] 🟡 **기업 9곳 출처**: 기업별 입력·출력 내용에 출처 링크가 없습니다. 발표에 쓸 기업만 골라서 링크를 답니다.
  - 확인(11/8): 온코크로스만 일부 확인 (대표 김이랑, 원발 부위 AI 개발 중). 나머지 8곳 미확인
  - 결정:다수 기업을 무리하게 나열하지 않고, 글로벌 기업 1곳과 국내 기업 1곳으로 압축 선별하여 공식 출처 링크를 명기했습니다.
- [x] 🟡 **환율 기준일**: 1달러 = 1,350원의 기준 날짜를 적습니다.
  - 결정:환율 산정 시점의 투명성을 위해 기준 날짜를 명시하기로 결정했습니다. (2024.11.08 기준 1달러=1,380원대)으로 변경했습니다.

## ⑤ 사용자 조사 (여은지)

파일: [5_2_사용자조사_여은지.md](./5_2_사용자조사_여은지.md)

- [x] 🔴 **임의 수치 (판독 시간 70% 단축, 3초)**: 출처가 없는 가정입니다. "목표" 또는 "가정"이라고 표시하거나 뺍니다. 3초는 우리 모델로 실제 추론 시간을 재서 바꿉니다.
  - 확인(11/8, 김지연): 실측값은 [5_3_시장사용자_보완_김지연.md](./5_3_시장사용자_보완_김지연.md) 3절
  - 결정:미검증된 '70% 단축' 표현을 삭제하였고, 실제 추론 시간으로 작성하였습니다.
- [x] 🔴 **"확진" 표현**: 시장성 조사와 마찬가지로 "진단 보조", "후보 제시"로 통일합니다.
  - 결정:"확진" 표현은 전부 삭제하였습니다.
- [x] 🟡 **출처 링크**: 청년의사 설문(2024.07)과 팜이데일리 인터뷰의 기사 링크를 추가합니다. 인터뷰 대상자 이름과 소속이 원문과 맞는지 확인합니다.
  - 확인(11/8, 김지연): 청년의사 89.5%는 원문과 일치. 대상은 "대한암학회 회원 200명". 팜이데일리 인터뷰는 원문을 못 찾았고, 온코크로스 대표는 김이랑이라 이름이 다름 → 대체 근거 정리: [5_3_시장사용자_보완_김지연.md](./5_3_시장사용자_보완_김지연.md) 1절
  - 결정:청년의사 기사 원문 링크는 첨부하고 대상을 수정하였습니다. 또한 원문 미확인 인터뷰는 삭제하였습니다.
- [x] 🟡 **"수천 개 변이를 의사가 일일이 대조"**: As-Is 표의 이 표현도 실제 변이 수(위 시장성 조사 항목)에 맞게 고칩니다.
  - 확인(11/8): 위 "4,000개" 항목과 같은 근거로 사실과 다름
  - 결정:4,384개에 달하는 유전자 패널 중 silent 변이를 제외한 유전자 수 기준 실제 환자당 변이는 중앙값 10개(아형별 평균 약 3~108개) 수준으로 희소하게 흩어져 있어 희소하게 나타난다는 EDA 팩트에 맞춰, As-Is 표의 표현을 "4,384개 패널 중 환자별 수십~수백 개 희소 변이를 가이드라인과 수작업 대조"로 사실에 부합하도록 정정했습니다.

👍 좋은 점: 원발부위불명암(CUP) 이야기는 우리 문제와 잘 맞습니다. 26개 라벨이 사실상 "어느 장기의 암인지"이기 때문에, "변이만 보고 원발 부위 후보 Top-3 제시"는 설득력 있는 활용처입니다.
