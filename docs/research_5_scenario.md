| 용어 | 쉽게 말하면 |
|---|---|
| NGS | 차세대 염기서열 분석. 암 조직에서 수백 개 유전자의 변이를 한 번에 읽는 검사 |
| 원발부위불명암 (CUP) | 암이 퍼진 곳은 찾았는데, 처음 생긴 장기를 모르는 암 |

| TAT | 검사를 맡기고 결과가 나오기까지 걸리는 시간 |
| Top-3 정확도 | 모델이 내놓은 후보 3개 안에 정답이 들어 있는 비율 |

## 2. 국내 시장

은지님 자료는 글로벌 숫자만 있어서 국내 숫자를 보완했습니다.

### 2-1. 국내 NGS 검사는 빠르게 늘고 있음

| 지표 | 수치 | 출처 |
|---|---|---|
| 건강보험 청구 NGS 패널 검사 건수 | 2017년 5,436건 → 2021년 29,557건 (**5.4배**) | Cancer Res Treat (2024), 국내 건강보험 청구 데이터 분석 [PMC10789967](https://pmc.ncbi.nlm.nih.gov/articles/PMC10789967/) |

※ 2021년 값은 논문에서 "아직 완전하지 않은 자료"라고 밝힌 숫자입니다.

| 시기 | 내용 | 출처 |
|---|---|---|
| 2017년 | NGS 패널 검사가 **조건부 선별급여**로 들어옴 (환자 부담 50%) | [대한민국 정책브리핑, 2017-02-16](https://www.korea.kr/news/policyNewsView.do?newsId=148829169) |
| 2023-12-01 | 폐암만 50% 유지, 그 외 고형암·혈액암 등은 **환자 부담 80%로 상향** | [메디칼타임즈](https://medicaltimes.com/Main/News/NewsView.html?ID=1167271) |
| 진행 중 | 심평원이 선별급여 적합성 재평가 중 (2028년 2차 평가 예정) | 위 기사 |

### 2-3. 우리 프로젝트에 주는 의미

- 검사 건수는 늘고 있어서, **이미 나온 NGS 결과를 더 잘 활용하는 도구**는 수요가 있습니다.
- 반대로 환자 부담이 커지는 추세라서, 검사를 더 하게 만드는 서비스보다 **추가 비용 없이 이미 있는 결과를 해석해주는 보조 도구**가 현실적입니다.

## 3. 우리 모델 실측 (김지연 v1, train만 사용)

은지님 자료의 "3초 만에 Top-3", "70% 단축"은 가정이었으므로, 실제로 잴 수 있는 것을 쟀습니다.
측정 방법: train만으로 5-fold CV(seed 42)를 돌려 OOF 확률로 Top-k를 계산했습니다. 추론 시간은 저장된 모델로 train 환자 100명을 한 명씩 예측한 시간입니다. test는 사용하지 않았습니다.

| 지표 | 값 |
|---|---|
| Top-1 정확도 | 39.6% |
| **Top-3 정확도** | **66.8%** |
| Macro F1 (CV) | 0.4069 (기존 결과와 같음 → 재현 확인) |
| 환자 1명 추론 시간 (중앙값 / 최대) | **0.15초 / 0.24초** (맥북, CPU) |

Top-3 정확도가 낮은 아형: CESC 자궁경부암 35.5%, DLBC 림프종 44.7%, LIHC 간암 48.1%, BRCA 유방암 50.8%, LUAD 폐선암 53.3%

**발표에서 쓸 수 있는 표현**
- "3초" 대신 → "환자 1명 결과가 **1초 안에** 나옴 (실측 0.15초)"
- "정확히 확진" 대신 → "후보 3개 안에 정답이 들어 있는 비율 **약 67%** (train 교차검증 기준)"
- 리더보드(test) 점수는 CV보다 낮게 나왔으므로(Public 0.31), 실제 성능은 이보다 낮을 수 있다고 함께 밝힙니다.

> "70% 단축"은 실제 판독 시간을 재지 않으면 말할 수 없습니다. 발표에서는 쓰지 않거나 "목표"로만 표시합니다.

## 4. 사용 시나리오: 원발부위불명암(CUP) 환자

### 4-1. 왜 CUP인가

- CUP는 악성 상피성 종양(암의 대부분을 차지하는 종류)의 약 3~5%로 알려져 있습니다. ([Pavlidis & Pentheroudakis, Lancet 2012](https://doi.org/10.1016/S0140-6736(11)61178-1), 원문 수치는 발표 전에 한 번 더 확인)
- 처음 생긴 장기를 모르면 어떤 치료를 쓸지 정하기 어렵습니다.
- 우리 데이터의 26개 라벨이 대부분 "어느 장기의 암인지"이기 때문에, **변이만 보고 처음 생긴 장기 후보를 좁혀주는 것**이 우리 모델과 가장 잘 맞는 쓰임입니다.
- 국내에서도 같은 문제를 노리는 기업이 있습니다. 온코크로스는 원발 부위를 찾는 AI(온코파인드)를 개발 중이라고 밝혔습니다 (개발 단계, 성능은 회사 측 설명).

### 4-2. 흐름 (입력 → 출력)

```
① 환자: 간에서 암 발견, 처음 생긴 곳은 불명
        ↓
② 병원: 조직으로 NGS 패널 검사 → 유전자별 변이 목록 (예: TP53 R175H, APC R1450*)
        ↓
③ 우리 도구: 변이 목록 업로드 → 26개 아형 중 후보 Top-3 + 확률 + 근거 유전자
        예) COAD(대장) 0.52 / STES(위·식도) 0.21 / PAAD(췌장) 0.09
            근거: APC 절단 변이 → 대장암에서 흔함
        ↓
④ 의사: 후보를 참고해 대장내시경 등 추가 검사 순서를 정함 → 최종 진단은 의사가 내림
```

### 4-3. 이 시나리오에서 조심할 것 (발표 때 한계로 말하기)

- 우리 모델은 **원발암(처음 생긴 곳의 암)** 데이터로 학습했습니다. 전이된 암에서도 같은 성능이 나오는지는 검증하지 않았습니다.
- 26개 라벨에 없는 암이면 맞힐 수 없습니다.
- 출력은 **후보 제시**이지 확진이 아닙니다. (⑥ 규제·윤리와 연결)
- 데이터에는 변이만 있고 유전자 발현, 복제수 변이(CNV) 같은 정보는 없습니다.

## 5. 사용자 피드백 질문지 (초안)

데모 화면이 생기면 주변 사람(가능하면 의료·바이오 쪽)에게 보여주고 아래를 묻습니다.
응답자의 이름과 연락처는 문서에 적지 않고, 직군만 적습니다.

**응답자 정보**
1. 직군: 의사 / 간호사 / 연구원 / 바이오·의료 전공 학생 / 기타

**이해도**
2. 결과 화면(Top-3 후보와 확률)을 보고 무엇을 뜻하는지 바로 이해되나요? (1~5점)
3. "근거 유전자" 설명이 결과를 믿는 데 도움이 되나요? (1~5점)

**쓸모**
4. 이런 도구가 있다면 어떤 상황에서 쓰고 싶나요? (자유 응답)
5. Top-3 안에 정답이 있을 확률이 약 67%라면 참고용으로 충분한가요? (예 / 아니오 / 모르겠음)
6. 결과 화면에 꼭 추가됐으면 하는 정보는? (자유 응답)

**우려**
7. 이 도구를 쓸 때 가장 걱정되는 점은? (오진, 책임 소재, 개인정보, 기타)
8. 이 도구를 실제로 쓰려면 무엇이 먼저 증명되어야 할까요? (자유 응답)

**결과 정리 방법**: 점수 문항은 평균을, 자유 응답은 비슷한 것끼리 묶어서 상위 3개를 정리합니다. 발표에는 "N명에게 받은 피드백 → 바꾼 점"으로 넣습니다.
