# 자료 검토 체크리스트

원본 파일은 그대로 두고, 팀 논의 후 원본이나 research.md에 반영합니다. 반영하면 체크하고 결정 내용을 적습니다.

| 표시 | 뜻 |

## ② 유전자·경로 지식 → 파생변수 (여은지)

- [ ] 🔴 **자료 4 `subclass_specific_marker_score`**: 정답(SUBCLASS)을 보고 아형별 자주 나오는 유전자를 고르는 피처입니다. 규칙 위반은 아니지만 **CV fold 안에서 train 부분으로만** 골라야 CV 점수가 부풀려지지 않습니다. ([data_leakage.md](./data_leakage.md) 4번)
  - 결정:
- [ ] 🔴 **자료 3 OncoKB**: OncoKB 데이터베이스를 내려받아 쓰면 외부 데이터입니다. "동의 변이 걸러내기, 핫스팟 플래그" 아이디어만 쓰고, 기준은 train에서 직접 정합니다.
  - 결정:
- [ ] 🔴 **자료 1 경로 유전자 목록**: 논문의 경로 유전자 이름을 코드에 적어 쓰는 것이 허용되는지 운영진 답변 대기 중입니다. "운영진 확인 후 사용"이라고 표시합니다. ([data_leakage.md](./data_leakage.md) 8번)
  - 결정:
- [ ] 🟡 **변이 종류 보완**: "첫 글자와 끝 글자가 다르면 기능 변이"만 적혀 있습니다. `*`(nonsense, 단백질이 중간에 끊김)와 `fs`(frameshift)도 있고, 이 둘은 기능을 더 크게 망가뜨리는 변이입니다.
  - 결정:
- [ ] 🟡 **한 칸에 변이 여러 개**: 공백으로 구분된 변이가 여러 개 들어 있는 칸이 약 2만 2천 개입니다. 칸 개수와 실제 변이 개수가 다릅니다.
  - 결정:
- [ ] 🟡 **자료 2 `patient_total_mutation_count`**: 베이스라인의 `n_mut`과 같은 피처입니다. "이미 있음"으로 표시합니다.

## ⑤ 시장성 조사 (여은지)

파일: [research_5_market.md](./research_5_market.md)

Grand View Research 원문과 숫자를 대조했습니다 (2026-11-08).
- ✅ 바이오마커 시장 269억 → 653억 달러 (2025→2033, CAGR 11.8%), 유전체 49.7%, 진단 58.5%, 북미 41.6%
- ✅ 암 유전체 진료 시장 181.2억 → 509.7억 달러 (2023→2030, CAGR 16.0%)

- [ ] 🔴 **"NGS가 가장 빠른 성장률"**: 원문과 다릅니다. 원문에서 가장 빨리 성장하는 부문은 기술은 마이크로어레이(19.0%), 제품은 서비스(24.1%), 용도는 신약 개발(18.5%)입니다.
  - 결정:
- [ ] 🔴 **"환자 1명당 4,000개가 넘는 유전자 변이"**: 유전자 컬럼이 4,384개인 것이고, 대부분은 WT(변이 없음)입니다. 실제 변이 수는 아형마다 평균 약 3개(LAML)에서 180개(UCEC)입니다.
  - 결정:
- [ ] 🔴 **"확진", "정확히 확진"**: AI가 확진한다는 표현은 ⑥ 규제 쪽에서 문제가 됩니다. "진단 보조", "후보 제시"로 통일합니다.
  - 결정:
- [ ] 🟡 **"68조와 88조의 교집합"**: 두 시장은 겹치는 부분이 있어서 이렇게 쓰면 규모가 실제보다 커 보일 수 있습니다. "두 시장에 걸쳐 있다" 정도로 바꿉니다.
  - 결정:
- [ ] 🟡 **기업 9곳 출처**: 기업별 입력·출력 내용에 출처 링크가 없습니다. 발표에 쓸 기업만 골라서 링크를 답니다.
  - 결정:
