## 1. 한 줄 요약

> 국내외에서 NGS 검사는 빠르게 늘고 있지만 결과 해석은 오래 걸립니다. 우리 도구는 **이미 나온 변이 결과만으로 암이 처음 생긴 장기 후보 3개를 1초 안에 보여주는, 의료진의 판단을 돕는 도구**입니다. 현재는 연구용 프로토타입(Research Use Only)입니다.

## 2. 시장 (확인된 숫자)

**글로벌** ([Grand View Research](https://www.grandviewresearch.com/industry-analysis/cancer-biomarker-market), 원문 대조 완료)
- 암 바이오마커 시장: 269억 달러(2025) → 653억 달러(2033), 연 11.8% 성장
  - 그중 유전체 바이오마커가 49.7%, 진단 용도가 58.5%
- 암 유전체 진료 시장: 181.2억 달러(2023) → 509.7억 달러(2030), 연 16.0% 성장 ([원문](https://www.grandviewresearch.com/industry-analysis/genomics-in-cancer-care-market))

**국내** ([Cancer Res Treat 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10789967/), 건강보험 청구 데이터)
- NGS 패널 검사: 2017년 5,436건 → 2021년 29,557건 (**5.4배**)
- 표적항암제 환자 중 NGS 검사 비율: 13% → 31.3%
- 단, 2023년 12월부터 폐암 외에는 환자 부담 50% → 80%로 올라감

## 3. 사용자

**누구를 위한 도구인가**
- 1순위: 병리과·혈액종양내과 의사 (진단 보조)
- 2순위: 유전체 분석 기관·연구원 (해석 자동화)

**왜 필요한가 (확인된 근거)**
- 대한암학회 회원 200명 중 **89.5%가 NGS 검사를 필수**라고 응답했고, 절반 넘게 현재 지원이 부족하다고 봄 ([청년의사 2024](http://www.docdocdoc.co.kr/news/articleView.html?idxno=3018507))
- NGS 결과가 나오기까지 **최대 6주**가 걸리고, 병원마다 기다리는 시간이 다름 ([팜뉴스 2023, 병리과 교수 인터뷰](https://www.pharmnews.com/news/articleView.html?idxno=234464))

## 4. 우리 도구가 하는 일

**대표 사용 장면: 원발부위불명암(CUP)**
- 암이 퍼진 곳은 찾았지만 처음 생긴 장기를 모르는 경우입니다. **악성 상피성 종양의 약 3~5%**가 여기에 해당합니다 ([Pavlidis & Pentheroudakis, Lancet 2012](https://doi.org/10.1016/S0140-6736(11)61178-1)).
- 우리 26개 라벨이 대부분 "어느 장기의 암인지"라서 가장 잘 맞는 쓰임입니다.

**입력 → 출력**
```
NGS 변이 목록 (예: TP53 R175H, APC R1450*)
   → 우리 모델
   → 후보 Top-3 + 확률 + 근거 유전자*
   → 의사가 추가 검사 순서를 정하고 최종 진단
```

\* 근거 유전자는 "모델이 판단에 많이 참고한 유전자"이며 그 암의 원인 유전자가 아닙니다. AI 기본법이 고영향 AI에 요구하는 "결과 설명 방안"에 대응하는 기능으로 소개할 수 있습니다 ([6_1](./6_1_규제윤리_박종부.md) 3-2절).

**실측 성능** (김지연 v1, train 교차검증)
- 후보 3개 안에 정답이 있을 확률: **66.8%**
- 환자 1명 결과: **0.15초**
- 리더보드(test) 점수는 CV보다 낮게 나왔으므로 실제 성능은 이보다 낮을 수 있음
- 팀 최고 리더보드 점수(test 전체 기준): **Macro F1 0.3236** (김지연 v2, 11/9). 발표에서 성능을 말할 때는 CV 숫자 대신 이 점수를 기준으로 함

**경쟁·비슷한 서비스와 차이** (기업 표는 5_1 참고)
- Tempus 등은 조직, 혈액, 진료기록을 모두 받아야 함 → 우리는 **변이 목록 하나만** 필요
- 국내 온코크로스는 원발 부위 AI "온코파인드AI" **개발 완료**를 발표함 (2025.4 보도, 회사 측 발표). **전사체(RNA-Seq) 데이터**를 쓰는 방식이라 별도 검사가 필요함 → 우리는 **이미 시행한 NGS 패널의 변이 목록만** 씀 ([5_4](./5_4_시장사용자_규제연계_박종부.md) 2-3절)
- 성능 비교는 하지 않음 (회사 측 수치가 검증되지 않았음)

## 5. 발표에서 쓸 표현 / 쓰지 않을 표현

| 쓰지 않음 | 대신 이렇게 |
|---|---|
| 확진, 정확히 확진, 판정 | 예측 보조, 후보 제시, 의료진 의사결정 지원 |
| 의사 대체 | 의료진의 판단을 돕는 도구 |
| 오진 없음, 안전함 | 쓰지 않음 (안전성 과장 광고 금지) |
| 정확도 OO%로 진단 가능 | 리더보드 Macro F1 0.32 (test 기준). Top-3 66.8%를 쓸 때는 "train 교차검증 기준, 실제는 더 낮을 수 있음"을 함께 표시 |
| 3초 만에 | 1초 안에 (실측 0.15초) |
| 판독 시간 70% 단축 | 쓰지 않음 (잴 방법 없음) 또는 "목표"로 표시 |
| 환자 1명당 변이 4,000개 | 유전자 4,384개를 검사, 환자 1명당 기능 변이가 있는 유전자는 **중앙값 10개** (silent 제외, 아형별 평균 약 3~108개) |
| 6,199개 유전자 (대회 설명) | 유전자 4,384개, 학습 환자 6,201명 (제공 데이터 기준) |
| (표시 없음) | 연구용 프로토타입 (Research Use Only) |
| NGS가 가장 빠르게 성장 | 유전체 바이오마커가 시장의 절반 (49.7%) |

- 이전 표기 "아형마다 평균 3~180개"는 한 칸의 변이 표기를 하나하나 다 센 값(변이 표기 수)입니다. 발표에서는 기능 의미가 약한 silent를 빼고 **유전자 수 기준**으로 통일합니다 ([5_4](./5_4_시장사용자_규제연계_박종부.md) 2-5절).

## 6. 한계 (발표 때 같이 말하기)

- 원발암 데이터로 학습했고, 전이암에서 검증하지 않았음
- 26개 라벨에 없는 암은 맞힐 수 없음
- 변이 정보만 있고 유전자 발현, 복제수 변이(CNV)는 없음
- 출력은 후보 제시이며, 실제 진료에 쓰려면 의료기기 인허가가 필요함 (3등급 가능성, 추정. [6_1](./6_1_규제윤리_박종부.md) 1-1절)
- **겹치는 라벨**: KIRC·KIPAN, LGG·GBMLGG는 같은 암을 다른 묶음 이름으로 부른 것이라, 변이만으로는 구분할 수 없는 환자가 많음 (KIRC의 81%, LGG의 76%가 상대 라벨 환자와 변이가 같음, 이 환자들의 정확도 0.19)
- 학습 데이터가 서양인 중심일 가능성 (라벨 체계상 TCGA 계열로 추정). 한국인 환자 성능은 외부 검증이 필요함
- 변이가 하나도 없는 환자(silent 제외 기준 train 121명)는 근거 없이 예측하게 됨 → 확신도가 낮으면 "판단 보류" 표시
- CV와 리더보드 차이가 0.1 이상으로 커서, test 환자가 train과 다르게 생겼을 가능성이 있음
- 대회 데이터는 비영리 목적으로만 쓸 수 있어 사업화 시 별도 데이터 확보가 필요함 (대회 규칙 제7조)
