## 1. 한 줄 요약

> 국내외에서 NGS 검사는 빠르게 늘고 있지만 결과 해석은 오래 걸립니다. 우리 도구는 **이미 나온 변이 결과만으로 암이 처음 생긴 장기 후보 3개를 1초 안에 보여주는 진단 보조 도구**입니다.

---

## 2. 시장 (확인된 숫자)

**글로벌** ([Grand View Research](https://www.grandviewresearch.com/industry-analysis/cancer-biomarker-market), 원문 대조 완료)
- 암 바이오마커 시장: 269억 달러(2025) → 653억 달러(2033), 연 11.8% 성장
  - 그중 유전체 바이오마커가 49.7%, 진단 용도가 58.5%
- 암 유전체 진료 시장: 181.2억 달러(2023) → 509.7억 달러(2030), 연 16.0% 성장 ([원문](https://www.grandviewresearch.com/industry-analysis/genomics-in-cancer-care-market))

**국내** ([Cancer Res Treat 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10789967/), 건강보험 청구 데이터)
- NGS 패널 검사: 2017년 5,436건 → 2021년 29,557건 (**5.4배**)
- 표적항암제 환자 중 NGS 검사 비율: 13% → 31.3%
- 단, 2023년 12월부터 폐암 외에는 환자 부담 50% → 80%로 올라감

## 3. 사용자

**누구를 위한 도구인가**
- 1순위: 병리과·혈액종양내과 의사 (진단 보조)
- 2순위: 유전체 분석 기관·연구원 (해석 자동화)

**왜 필요한가 (확인된 근거)**
- 대한암학회 회원 200명 중 **89.5%가 NGS 검사를 필수**라고 응답했고, 절반 넘게 현재 지원이 부족하다고 봄 ([청년의사 2024](http://www.docdocdoc.co.kr/news/articleView.html?idxno=3018507))
- NGS 결과가 나오기까지 **최대 6주**가 걸리고, 병원마다 기다리는 시간이 다름 ([팜뉴스 2023, 병리과 교수 인터뷰](https://www.pharmnews.com/news/articleView.html?idxno=234464))

## 4. 우리 도구가 하는 일

**대표 사용 장면: 원발부위불명암(CUP)**
- 암이 퍼진 곳은 찾았지만 처음 생긴 장기를 모르는 경우입니다.
- 우리 26개 라벨이 대부분 "어느 장기의 암인지"라서 가장 잘 맞는 쓰임입니다.

**입력 → 출력**
```
NGS 변이 목록 (예: TP53 R175H, APC R1450*)
   → 우리 모델
   → 후보 Top-3 + 확률 + 근거 유전자
   → 의사가 추가 검사 순서를 정하고 최종 진단
```

**실측 성능** (김지연 v1, train 교차검증)
- 후보 3개 안에 정답이 있을 확률: **66.8%**
- 환자 1명 결과: **0.15초**
- 리더보드(test) 점수는 CV보다 낮게 나왔으므로 실제 성능은 이보다 낮을 수 있음

**경쟁·비슷한 서비스와 차이** (기업 표는 5_1 참고)
- Tempus 등은 조직, 혈액, 진료기록을 모두 받아야 함 → 우리는 **변이 목록 하나만** 필요
- 국내 온코크로스도 원발 부위 AI를 개발 중 (회사 측 설명, 개발 단계)

## 5. 발표에서 쓸 표현 / 쓰지 않을 표현

| 쓰지 않음 | 대신 이렇게 |
|---|---|
| 확진, 정확히 확진 | 진단 보조, 후보 제시 |
| 3초 만에 | 1초 안에 (실측 0.15초) |
| 판독 시간 70% 단축 | 쓰지 않음 (잴 방법 없음) 또는 "목표"로 표시 |
| 환자 1명당 변이 4,000개 | 유전자 4,384개를 검사, 실제 변이는 아형마다 평균 3~180개 |
| NGS가 가장 빠르게 성장 | 유전체 바이오마커가 시장의 절반 (49.7%) |

## 6. 한계 (발표 때 같이 말하기)

- 원발암 데이터로 학습했고, 전이암에서 검증하지 않았음
- 26개 라벨에 없는 암은 맞힐 수 없음
- 변이 정보만 있고 유전자 발현, 복제수 변이(CNV)는 없음
- 출력은 후보 제시이며, 의료기기 허가 등은 ⑥ 규제·윤리에서 정리
