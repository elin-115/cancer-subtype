# ③ 모델 해석: 중요 피처와 혼동 행렬 (v2-N5)

작성: 김지연 (2026-11-09)  
관련 문서: [4_2_맞춤치료_표적치료근거_김도엽.md](./4_2_맞춤치료_표적치료근거_김도엽.md) 8절 "다음 작업", [6_1_규제윤리_박종부.md](./6_1_규제윤리_박종부.md) 3-2절 "설명 가능성"

> 대상 모델: **v2-N5** (베이스라인 XGBoost + 변이 유전자 수 `n_mut` + 핫스팟 573개). 11/9 기준 팀 최고 리더보드 **0.3236**  
> 모든 숫자는 **train만** 사용했습니다. 혼동 행렬은 5-Fold 교차검증의 검증 예측(OOF, CV 0.4138)으로 만들었습니다.

## 먼저 알아둘 것

- **중요도**는 "모델이 아형을 나눌 때 그 피처로 얼마나 많이 구분했는지"를 합한 값입니다 (XGBoost total gain, 전체를 100%로 환산).
- 중요도가 높다고 **그 유전자가 암의 원인이라는 뜻은 아닙니다.** "모델이 많이 참고했다"는 뜻입니다.
- 핫스팟 피처는 `유전자_위치` 이름입니다 (예: `IDH1_132` = IDH1 132번 자리 변이). 유전자 이름만 있는 피처는 "그 유전자에 변이가 있다/없다"입니다.

## 2. 해석과 주의할 점

- **`n_mut`(변이 개수)이 압도적 1위 (17.5%)**  
  암마다 변이 수가 크게 달라서(THYM 중앙값 2개 vs SKCM 85.5개) 당연한 결과입니다. 다만 11/9 리더보드에서 **개수·비율 피처를 더하면 오히려 떨어졌기** 때문에, test에서는 변이 개수의 분포가 다를 가능성이 있습니다. → 다음 실험: `n_mut`을 뺀 버전을 리더보드로 확인 ([2_0](./2_0_유전자경로_종합.md) 6-5절)
- **⚠️ ACC 전용 패턴 2개 (LRIG1_24, SOWAHC_42)**  
  ACC 환자에게서만 나오고, SOWAHC `L42L`은 아미노산이 바뀌지 않는 silent 변이입니다. 생물학적 의미보다는 **해당 코호트의 검사 방식·처리 과정에서 생긴 고유 패턴(배치 효과)**일 가능성이 있습니다. 발표에서 "원인 유전자"처럼 소개하지 않습니다.
- **잘 알려진 암 유전자가 상위권**: TP53, VHL(신장암), APC(대장암), PTEN·PIK3CA(자궁내막암·유방암), IDH1·ATRX(뇌종양), NPM1(백혈병)처럼 교과서적인 조합이 상위에 있어, 모델이 생물학적으로 말이 되는 신호를 쓰고 있습니다.

## 3. 혼동 행렬: 많이 헷갈린 아형 쌍

5-Fold OOF 기준, "정답 → 모델 예측" 순서입니다. 비율은 정답 아형 환자 중 그렇게 틀린 비율입니다.

| 순위 | 정답 → 예측 | 환자 수 | 비율 | 설명 |
|---|---|---|---|---|
| 1 | KIPAN → KIRC | 217 | 42% | **겹치는 라벨** (KIPAN은 KIRC를 포함하는 신장암 묶음) |
| 2 | GBMLGG → LGG | 200 | 43% | **겹치는 라벨** (GBMLGG는 GBM+LGG 묶음) |

**겹치는 라벨 쌍 요약**
- KIRC ↔ KIPAN: 347건 (KIRC 334명 중 130명, KIPAN 515명 중 217명)
- LGG ↔ GBMLGG: 251건 (LGG 229명 중 51명, GBMLGG 461명 중 200명)
- → 두 쌍이 전체 오답의 약 16%를 차지합니다. 변이가 완전히 같은 환자가 많아서 모델 성능으로 풀 수 없는 **데이터 구조의 한계**입니다 ([5_4](./5_4_시장사용자_규제연계_박종부.md) 2-7절).

**변이가 적은 암끼리 헷갈림**
- PCPG, THCA, PRAD, THYM, LAML은 환자 1명당 변이 유전자가 중앙값 2~6개뿐이라 모델이 쓸 단서가 적습니다.
- 서비스에서는 이런 환자에게 확신도가 낮으면 "판단 보류"를 표시하는 근거가 됩니다 ([6_1](./6_1_규제윤리_박종부.md) 4-2절).

- 잘 맞히는 아형은 **뚜렷한 대표 변이**가 있습니다 (ACC: 고유 패턴, SKCM·THCA: BRAF 600, COAD: APC, UCEC: PTEN·PIK3CA).
- KIPAN·KIRC는 겹치는 라벨 때문에, CESC·PAAD·SARC는 대표 변이가 약해서 낮습니다.
- 주의: CV(0.41)보다 리더보드(0.32)가 낮으므로 test에서의 아형별 성능은 이보다 낮을 수 있습니다.
