## 0. 보내는 방법

**데모 링크**: `04_demo.ipynb` 마지막 셀을 실행하면 나오는 `https://….gradio.live` 주소 (노트북이 켜져 있는 동안만 작동)

**주의**
- 데모 예시는 모두 **가상 환자**입니다. 대회 데이터(train/test) 환자의 변이를 직접 입력하거나 화면 캡처해서 보내지 않습니다 (대회 규칙 제7조: 미참가자에게 데이터 전송 금지).
- 응답자의 이름·연락처는 받지 않고, 문서에는 대상 구분(A/B)과 직군만 적습니다.
- 응답은 구글 폼이나 디스코드 답장으로 받습니다. 구글 폼으로 만들면 링크를 이 문서에 추가합니다.

**보내는 메시지 예시 (A. 해커톤 참가자)**
> 안녕하세요! 1조 ONCOVA입니다 🙂 저희가 만든 암 종류 예측 데모를 3분만 써봐주실 수 있을까요?
> 링크: (데모 주소) / 질문은 아래 6개예요. 원하시면 저희도 다른 조 데모 써보고 피드백 드릴게요!

**보내는 메시지 예시 (B. 일반인)**
> 해커톤에서 만든 AI 데모인데 3분만 써봐줄 수 있어? 의학 지식 없어도 돼!
> 링크 들어가서 왼쪽 "예시 환자"를 하나 골라 "예측하기"를 누르고, 결과 보고 아래 질문에 답해주면 돼.

## A. 해커톤 참가자용 (6문항, 약 3분)

**해볼 것**: 예시 환자 2~3개를 고르고, 원하면 변이를 직접 바꿔서 넣어보기

1. 결과(암 종류 후보 3개와 확률)를 보고 무엇을 뜻하는지 바로 이해되나요?  
   ① 전혀 아니다 ② 아니다 ③ 보통 ④ 그렇다 ⑤ 매우 그렇다
2. "근거 유전자"가 결과를 납득하는 데 도움이 되나요? (예: 갑상선암 예측의 근거가 BRAF_600)  
   ① ~ ⑤
3. 후보를 1개가 아니라 3개 보여주는 것이 도움이 되나요?  
   ① 1개면 충분 ② 3개가 좋음 ③ 더 많이 보고 싶음 ④ 모르겠음
4. 결과 화면에 꼭 추가됐으면 하는 정보는? (자유 응답)  
   예: 각 후보가 왜 나왔는지, 비슷한 환자 수, 치료 타깃 변이 표시 등
5. 이런 도구를 실제 병원에서 쓴다면, 환자 변이 데이터를 어떻게 처리하는 게 더 받아들여질까요?  
   ① 병원 밖 서버(클라우드)로 보내서 분석 ② 병원 안에 설치해서 분석 ③ 모르겠음  
   (박종부 제안, [5_4](./5_4_시장사용자_규제연계_박종부.md) 3-5절)
6. 이 도구를 쓸 때 가장 걱정되는 점은? (여러 개 선택)  
   ① 틀린 결과(오진) ② 책임이 누구에게 있는지 ③ 개인정보 ④ 결과를 너무 믿게 될까 봐 ⑤ 기타: ____

## B. 일반인용 (6문항, 약 3분)

**해볼 것**: 왼쪽 "① 예시 환자 고르기"에서 하나 고르기 → "예측하기" 누르기 → 다른 예시도 1~2개 해보기

1. 처음 화면을 봤을 때 무엇을 하는 도구인지 알 수 있었나요?  
   ① 전혀 모르겠다 ② 잘 모르겠다 ③ 보통 ④ 알 것 같다 ⑤ 바로 알았다
2. 어떻게 쓰는지(예시 고르기 → 예측하기) 헤맨 곳이 있었나요?  
   ① 없음 ② 조금 헤맴 ③ 많이 헤맴 → 어디서? ____
3. 결과를 보고, 이 도구가 하는 일을 한 문장으로 말한다면? (자유 응답)  
   → **"병을 진단해준다"** 고 답하면 오해한 것, **"후보를 알려준다 / 참고용이다"** 면 의도대로 이해한 것
4. 화면 아래 주의 문구(연구용, 진단 아님, 최종 판단은 의료진)가 눈에 들어왔나요?  
   ① 못 봤다 ② 봤지만 신경 안 씀 ③ 봤고 이해함
5. "변이 표기 읽는 법" 설명이 도움이 됐나요?  
   ① 안 읽음 ② 읽었지만 어려움 ③ 대충 이해됨 ④ 잘 이해됨
6. 가장 헷갈리거나 바뀌었으면 하는 점 하나는? (자유 응답)

| 대상 | 응답 수 | 점수 문항 평균 | 자유 응답에서 많이 나온 것 (상위 3개) | 그래서 바꾼 점 |
|---|---|---|---|---|
| A. 해커톤 참가자 | | | | |
| B. 일반인 | | | | |

- 점수 문항(①~⑤)은 평균을 내고, 자유 응답은 비슷한 것끼리 묶어서 상위 3개를 적습니다.
- B-3에서 "진단해준다"는 답이 몇 명인지 따로 셉니다 → 오해가 많으면 화면 문구를 고칩니다 ([6_1](./6_1_규제윤리_박종부.md) 1-4절 "진단 보조" 표현 원칙).
- 발표에는 **"N명에게 받은 피드백 → 바꾼 점"** 으로 넣습니다 (강사님이 강조한 "주변 사람에게 써보게 하고 피드백" 항목).
