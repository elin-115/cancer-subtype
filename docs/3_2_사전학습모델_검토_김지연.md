# ③ 사전학습 모델 검토 (논의 기록, 2026-11-06)

작성: 김지연
관련: [3_1_기존연구_모델_김도엽.md](./3_1_기존연구_모델_김도엽.md), [00_데이터누수_규칙.md](./00_데이터누수_규칙.md) 8번(운영진 문의)

대회 규칙상 논문으로 공개되고 법적 제약이 없는 사전학습 모델은 쓸 수 있어서, 우리 데이터에 쓸 만한지 검토했습니다.

**결론**: 지금은 피처 실험(변이 유형, fold 안 피처 선택)을 먼저 하고, 사전학습 모델은 운영진 답변을 받은 뒤 유전자 임베딩만 시간을 정해서 시도합니다.

**우선순위를 낮춘 이유**
- 데이터가 약 6천 명 × 유전자 4천 개의 0/1 표 데이터라서 트리 모델이 강한 조건입니다.
- 공개된 모델은 대부분 유전자 발현이나 염기·단백질 서열로 학습되어, 우리 입력(유전자 이름 + `V600E` 같은 변이 표기)과 잘 맞지 않습니다.
- 서열 같은 추가 정보가 필요한 모델은 외부 데이터 사용에 해당할 위험이 있습니다.

| 종류 | 예시 | 쓰는 방법 | 판단 |
|---|---|---|---|
| 유전자 임베딩 | Gene2vec(2019), Geneformer(2023), scGPT(2024) | 환자 = 변이 있는 유전자 벡터들의 평균. 희귀 유전자를 비슷한 유전자와 묶어주는 효과 | 가장 현실적. 임베딩 표가 외부 데이터로 보일 수 있어 확인 필요 |
| 단백질 언어모델 | ESM 계열 | missense 변이가 단백질에 미치는 영향 점수화 | 단백질 서열이 따로 필요해 외부 데이터 위험이 크고 계산도 무거움 |
| 미리 계산된 병원성 점수 | AlphaMissense 점수 표 | 변이별 점수 조회 | 모델이 아니라 점수 표라 외부 데이터일 가능성이 높음. 사용하지 않음 |
| 표 데이터 파운데이션 모델 | TabPFN | 표를 그대로 넣어 분류 | 클래스 수·피처 수 제한이 있어 바로 쓰기 어려움. 피처 선택 후 비교용 |

**사용하게 되면 지킬 것**
- 노트북에 논문 링크와 출처를 적습니다 (제출 규칙).
- 가중치 다운로드 코드까지 새 커널에서 오류 없이 실행되어야 합니다.
