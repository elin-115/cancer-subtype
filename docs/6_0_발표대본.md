**9. 접근 방식 [5:40, 55초]**  
입력은 유전자별 변이 표기입니다. 이걸 유전자마다 변이 있음/없음 0/1로 바꾸고, 변이가 있는 유전자 수와 핫스팟, 그리고 아미노산이 무엇에서 무엇으로 바뀌었는지의 비율을 더했습니다. 모델은 XGBoost이고 작은 아형이 묻히지 않게 불균형 가중치를 줬습니다. 학습 전에는 같은 환자의 중복 기록을 한 명으로 정리하고, 겹치는 라벨은 묶음을 먼저 고른 뒤 세부 아형을 따로 판정합니다. 출력은 26개 아형의 확률이고, 그중 상위 3개를 보여줍니다. 그리고 처음부터 데이터 누수 규칙을 문서로 정해서, 모든 기준은 train에서만 만들고 test는 값 세기도 하지 않았습니다.

**12. 피처를 더하면 CV만 올랐다 [8:25, 65초]**  
가장 크게 배운 점입니다. 교차검증 점수가 높은 모델일수록 리더보드는 오히려 낮았습니다. 세 모델을 섞은 앙상블은 CV 0.44였지만 리더보드는 0.30이었고, 핫스팟 모델은 CV 0.41인데 리더보드 0.32였습니다. 핫스팟처럼 있다/없다 정보는 test에서도 통했지만, 변이 종류 비율이나 튜닝, 앙상블은 CV만 올렸습니다. 예외가 두 번 있었는데, 데이터 속 중복 기록을 정리했을 때와, 아미노산 치환 패턴을 넣었을 때는 CV와 리더보드가 같이 올랐습니다. 여기부터는 김지연 님이 이어서 설명드리겠습니다.
