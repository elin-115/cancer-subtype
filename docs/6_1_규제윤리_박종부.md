## 0. 핵심 결론 (발표·README용 요약)

1. **해커톤 단계의 ONCOVA는 연구용 프로토타입**이므로 의료기기 인허가 대상이 아니다. 사업화 시에는 디지털의료기기(소프트웨어) 인허가가 필요하다.
2. 포지셔닝은 **"의료진의 최종 판단을 돕는 암 아형 예측 보조 도구"**로 한다. "진단", "판정" 같은 단정 표현은 쓰지 않는다.
3. 입력 데이터(유전자 변이 정보)는 **개인정보보호법상 민감정보**이며, 상용화 시 **가명처리 + 폐쇄환경 + 접근통제**가 기본 전제다.
4. 생명윤리법상 **유전정보 차별 금지(제46조)** 원칙을 서비스 사용목적 제한에 반영한다.
5. 대회 데이터는 **비영리 목적으로만 사용 가능**하므로, 사업화 시에는 별도 데이터 확보가 필요하다고 명시한다.

## 1. 의료 AI 인허가 — 디지털의료제품법

| 항목 | 내용 | ONCOVA 시사점 |
|---|---|---|
| 근거법 | 디지털의료제품법 시행(2025.1.24). 소프트웨어 형태 디지털의료기기는 인허가 시 원칙적으로 임상시험 등 자료 제출, 예외 사유 인정 시 면제·대체자료 가능 | 상용화 시 소프트웨어 의료기기(SaMD) 경로 |

| 중점 심사 항목 | 소프트웨어 검증, 유효성, 전자적 침해행위 보호, 사용적합성 | 성능 검증·보안 설계 필요 |

| 유사 제품 등급 | NGS 기반 유전성 유방암·난소암 시약 패널이 3등급 품목허가를 받은 사례(엔젠바이오, 2017) | 암 아형 분류 SW도 3등급 이상일 가능성 **(추정, 확인 필요)** |

## 5. 생명윤리법 (생명윤리 및 안전에 관한 법률)

### 5-1. 관련 조문 요약

| 조문 | 내용 | ONCOVA 관련성 |
|---|---|---|
| 제15조 (인간대상연구의 심의) | 인간대상연구는 원칙적으로 기관생명윤리위원회(IRB) 심의 필요. 제15조 제2항·시행규칙 제13조에 따라 위험이 미미한 연구 등은 심의 면제 가능 | 병원 데이터로 연구·검증할 때 해당 |
| 심의 면제 결정 | 면제 여부는 연구자가 아니라 **IRB가 결정**하며, 면제 신청서 제출이 필요한 것이 일반적 운영 | 연구자 자체 판단으로 면제 처리 불가 |
| 공개 데이터 활용 | 공개 공공데이터를 쓸 때도 원자료 생산기관의 IRB 번호를 확인·기재하도록 권고. 소속 IRB가 없으면 **공용IRB(irb.or.kr)** 이용 가능 | 향후 논문·사업화 시 참고 |
| 제46조 (유전정보에 의한 차별 금지) | 누구든지 유전정보를 이유로 교육·고용·승진·보험 등에서 차별 금지, 유전자검사 강요·결과 제출 강요 금지. 위반 시 제67조 벌칙 | 서비스 사용목적에 **보험·고용 심사 활용 금지** 명시 필요 |
| 제49조 (유전자검사기관) | 유전자검사를 하려는 기관은 질병관리청에 신고. 종사자는 최초·정기 유전자검사교육 이수 의무(시행규칙 제49조의6) | 아래 5-2 참고 |
| 제49조~제53조 | 유전자검사의 제한, 동의, 기록 보관 등 규율 | 검사기관과 협업 시 해당 |

### 5-2. ONCOVA는 "유전자검사기관"에 해당하는가?

- ONCOVA는 검체에서 유전자를 직접 분석하는 것이 아니라, **이미 생성된 변이 정보를 입력받아 아형을 예측하는 소프트웨어**다. 따라서 직접적인 유전자검사기관 신고 대상이 아닐 가능성이 높다. **(추정)**
- 다만 학계에서는 생명윤리법이 유전자검사의 **"분석-해석" 이원 구조**를 명확히 구분하지 않는다는 지적이 있다. ONCOVA가 "해석" 단계를 맡는 만큼 법 해석의 여지가 남는다.
- 현실적 사업 구조는 **신고된 유전자검사기관·병원에 SW를 공급**하는 B2B 모델이 규제상 가장 깔끔하다.

### 5-3. 해커톤 단계 판단

| 항목 | 판단 |
|---|---|
| IRB 심의 | 연구대상자를 직접 모집하거나 검체를 수집하지 않고 데이콘 제공 데이터만 사용하므로 해커톤 단계에서는 해당성 낮음 **(추정)** |
| 상용화·병원 데이터 사용 시 | IRB 심의(또는 면제 승인) 필수 |

| 외부 데이터 | 사용 불가 (사전 학습 모델은 사용 가능) | 파생변수는 대회 데이터 내에서만 생성 |
| Data Leakage | 인코딩·스케일링·결측치 처리 등에 test 데이터 활용 금지 | `00_데이터누수규칙` 문서와 연계 |
