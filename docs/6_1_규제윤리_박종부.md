### 1-1. 의료기기 해당 여부와 등급

- **출처**
  - 식약처, 「빅데이터 및 인공지능(AI) 기술이 적용된 의료기기의 허가·심사 가이드라인」(2017.11) — [메디칼타임즈 보도](https://www.medicaltimes.com/Main/view.html?ID=1115287)
  - 메디게이트뉴스, 식약처 AI 의료기기 허가 110개 품목 분석(2022.5) — [링크](https://medigatenews.com/news/2431153014)
  - 메디칼타임즈, 엔젠바이오 NGS 패널 3등급 허가 — [링크](https://www.medicaltimes.com/Main/view.html?ID=1122617)
- **핵심 내용**
  - 식약처 2017 가이드라인은 진료기록·의료영상·생체정보·**유전정보** 등 의료용 빅데이터에 AI를 적용한 소프트웨어가 의료기기인지 구분하는 기준을 담고 있다.
  - 2022년 4월 기준 AI 의료기기 110개 중 대부분이 2등급, 3등급은 19개, 1등급은 2개였다.
  - NGS 기반 암 유전자 검사 패널은 3등급 체외진단기기로 허가된 사례가 있다.
- **우리 프로젝트 적용**
  - 해커톤 단계의 ONCOVA는 **연구용 프로토타입**이므로 인허가 대상이 아니다.
  - 실제 진료에 쓰는 순간 유전정보로 암 종류를 판단하는 소프트웨어이므로 **의료기기에 해당할 가능성이 높다. (추정)**
  - 등급은 유사 사례(유전자 기반 암 체외진단, AI 암 진단 보조)가 모두 3등급이므로 **3등급 가능성이 높다. (추정, 식약처 품목 분류 확인 필요)**

| 2025.1 | 디지털의료제품법 시행 | SW 의료기기는 원칙적으로 임상시험 등 자료 제출, 예외 인정 시 면제·대체자료 가능 |
| 2025.5 | 디지털의료기기 가이드라인 6종 제·개정 | 하위규정 시행에 맞춘 세부 안내 |

  - AI 기반 제품은 허가·심사 결과를 공개하고 **학습데이터 정보를 투명하게 제공**해야 한다.
- **우리 프로젝트 적용**
  - 사업화 계획에 "성능 검증 자료 중심 인허가 경로"를 적을 수 있다.
  - 학습데이터 구성(출처, 암종별 샘플 수, 인종 구성)을 지금부터 문서로 정리해 두면 이후 허가 준비에 그대로 쓸 수 있다.

### 1-4. "진단 보조"와 "진단"의 차이

- **출처**
  - 메디게이트뉴스, AI 의료기기 허가 목록의 사용목적 표기(2022) — [링크](https://medigatenews.com/news/2431153014)
  - 아주경제, AI 기본법 고영향 AI 적용 기준(2026.1) — [링크](https://www.ajunews.com/view/20260121110211455)
  - 의료기기법 시행규칙 별표 7 「금지되는 광고의 범위」
- **핵심 내용**
  - 허가된 AI 제품의 사용목적은 대부분 "**의료인의 진단 결정을 보조**"하는 소프트웨어로 적혀 있다.
  - **주의:** "진단 보조"라고 해서 의료기기 규제를 피하는 것은 아니다. 진단 보조 SW도 3등급 허가를 받는다.
  - 차이가 생기는 곳은 **AI 기본법**이다. AI 결과를 사람이 검토하고 최종 결정하는 구조라면 고영향 AI에서 제외되며, 진단 보조 시스템도 사람이 최종 판단하면 제외된다는 것이 정부 설명이다. (자세한 내용은 5절)
  - 광고에서는 허가받지 않은 의료기기의 성능·효능 광고, 부작용을 전부 부정하거나 안전성을 부당하게 강조하는 광고가 금지된다.
- **우리 프로젝트 적용**

| 권장 표현 | 피해야 할 표현 | 이유 |
|---|---|---|
| 암 아형 **예측 보조**, 의료진 **의사결정 지원** | 암 아형 **진단**, **판정** | 사람 최종 판단 구조여야 고영향 AI 제외 논리가 성립 |
| 연구용 프로토타입 (Research Use Only) | "정확도 OO%로 진단 가능" | 미허가 의료기기의 성능·효능 광고 금지 |
| 후보 제시, 참고 정보 제공 | "의사 대체", "오진 없음" | 안전성 과장 광고 금지 |

| 제49조~제53조 | 유전자검사의 제한, 동의, 기록 보관 등 규율 | 검사기관과 협업 시 해당 |

- **우리 프로젝트 적용**
  - **ONCOVA는 유전자검사기관인가?** ONCOVA는 검체에서 유전자를 직접 분석하지 않고, 이미 생성된 변이 정보를 받아 아형을 예측하는 소프트웨어다. 따라서 직접적인 신고 대상이 아닐 가능성이 높다. **(추정)** 다만 학계에서는 생명윤리법이 유전자검사의 "분석-해석" 구조를 명확히 나누지 않는다는 지적이 있어, ONCOVA가 맡는 "해석" 단계에는 법 해석의 여지가 남는다.
  - 현실적인 사업 구조는 **신고된 유전자검사기관·병원에 SW를 공급하는 B2B 모델**이 규제상 가장 깔끔하다.
  - 해커톤 단계는 연구대상자 모집이나 검체 수집 없이 데이콘 제공 데이터만 쓰므로 IRB 해당성이 낮다. **(추정)** 상용화나 병원 데이터 사용 시에는 IRB 심의(또는 면제 승인)가 필수다.

### 4-2. 26개 라벨에 없는 암, 전이암에 쓸 때의 위험

- **출처**
  - Jiao et al., Nature Communications 2020, 변이 패턴 기반 원발·전이암 분류 — [링크](https://researchinformation.umcutrecht.nl/en/publications/a-deep-learning-system-accurately-classifies-primary-and-metastat/), [전문 PDF](https://escholarship.org/content/qt21n184f7/qt21n184f7.pdf)
  - Nguyen et al., CUPLR 원발부위 분류기(2022) — [링크](https://pmc.ncbi.nlm.nih.gov/articles/PMC9273599)
  - Liu et al., Frontiers 2021, 원발부위 추정 비교 — [링크](https://www.frontiersin.org/journals/cell-and-developmental-biology/articles/10.3389/fcell.2021.619330/pdf)
- **핵심 내용**
  - 전체 암의 약 **3~5%는 원발부위불명암(CUP)**이며, 이런 환자는 원발 장기를 알기 어려워 치료 선택이 제한된다. 변이 기반 분류기가 이 문제를 돕는 용도로 연구되고 있다.
  - Jiao et al. 분류기는 원발암 독립 검증에서 정확도 88%, **전이암에서는 83%**로 낮아졌다.
  - 같은 연구에서 **드라이버 유전자 정보를 추가하자 오히려 정확도가 떨어졌고**, 드라이버 유전자·경로만으로는 암종 분류 성능이 좋지 않았다. 대신 전장 유전체의 패신저 변이 분포가 핵심 특징이었다.
- **우리 프로젝트 적용**
  - **라벨 밖 암:** 분류 모델은 학습하지 않은 암이 들어와도 26개 중 하나로 **억지로 답한다**. 확신도가 낮을 때 "판단 보류" 또는 "학습 범위 밖 가능성"을 표시하는 기능이 필요하다.
  - **전이암:** 원발암 위주로 학습한 모델은 전이암에서 성능이 떨어질 수 있으므로, 사용 범위를 "원발암 검체 기준"으로 명시한다.
  - **입력 데이터의 한계:** 우리 데이터는 유전자 단위 변이 여부(6,199개 유전자, WT/변이)이고 전장 유전체 패신저 변이 분포가 아니다. 위 연구 결과를 보면 이 방식만으로는 성능 상한이 있을 수 있으므로, 한계로 말해 둔다. (`3_1_기존연구_모델` 문서와 연계)
  - **결과 표시:** 1순위 하나가 아니라 **상위 후보 여러 개와 확신도**를 함께 보여 주는 것이 "진단 보조" 포지셔닝과도 맞다.

| 시행 | 2026.1.22 본법·시행령 시행, 2026.7.21 개정법·개정 시행령 추가 시행 |
| 의료 분야 고영향 AI | 디지털의료제품법상 **3등급 이상** 디지털의료기기가 고영향 AI로 분류된다는 해석(법무법인 세미나) |
| 사람 개입 기준 | 사람이 결과를 검토하고 최종 결정하는 구조면 고영향 AI로 보지 않으며, 진단 보조 시스템도 사람이 최종 판단하면 제외(정부 발표 보도) |
| 고지 의무 | 고영향 AI·생성형 AI 기반 제품·서비스는 AI 기반 운영 사실을 이용자에게 사전 고지 |
| 고영향 AI 책무 | 위험관리, 결과 설명 방안, 이용자 보호, 사람의 관리·감독 등 (3-2 참고) |
| 제재 | 형벌 없이 최대 3,000만 원 과태료, 최소 1년 계도(유예) |

> **해석 차이 주의:** "3등급 이상 = 고영향"과 "사람 최종 판단 시 제외" 두 설명의 관계는 과기정통부 고시·가이드라인 원문 확인이 필요하다. 업계도 하위 법령에서 식약처 인증을 어디까지 인정할지 주목하고 있다.

- **우리 프로젝트 적용**
  - ONCOVA가 3등급 의료기기가 되면 고영향 AI로 분류될 가능성이 있으므로, 처음부터 **"의료진 최종 판단" 구조**와 **설명 기능(근거 유전자)**을 갖추는 것이 유리하다.
  - 서비스 화면에 "AI 기반 결과" 고지 문구를 넣는다.

  - 분석 SW 단독 검증 계획이 필요하다.

- [ ] 화면·약관에 "최종 판단은 의료진" 문구 표시
- [ ] 상위 후보 여러 개와 확신도를 함께 표시
- [ ] 확신도가 낮으면 "판단 보류 / 학습 범위 밖 가능성" 표시
- [ ] 근거 유전자 옆에 "모델 판단 근거이며 발병 원인과 다를 수 있음" 안내
- [ ] "AI 기반 결과" 고지 문구 표시
- [ ] 사용목적 제한: 보험·고용 등 심사 목적 활용 금지 (생명윤리법 제46조)
- [ ] 데이터 처리: 처리위탁 계약 또는 병원 내부 설치형 옵션, 학습 활용 시 가명처리 + 폐쇄환경
- [ ] 모델 버전·예측 기록 보관
- [ ] 학습데이터 개요(출처, 암종별 샘플 수, 인종 구성) 문서화
- [ ] GitHub 저장소에 원본 데이터 파일 미포함 확인

### 한계로 말할 것

- 학습 데이터가 서양인 중심일 가능성이 있어 **한국인 환자 성능은 외부 검증이 필요**하다.
- **26개 라벨 밖의 암**에는 쓸 수 없고, **전이암**에서는 성능이 떨어질 수 있다.
- 유전자 단위 변이 여부만 쓰므로 전장 유전체 기반 분류기보다 **성능 상한이 있을 수 있다**.
- 대회 데이터는 비영리 목적으로만 쓸 수 있어 **사업화 시 별도 데이터 확보**가 필요하다.
- 의료기기 등급, 유전자검사기관 해당 여부, 고영향 AI 해당 여부는 **공식 확인 전 추정**이다.
