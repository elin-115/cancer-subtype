## 1. 의료기기 규제

- [ ] 우리 도구(변이 목록 → 암 종류 후보 제시)는 의료기기에 해당하나요? 해당한다면 몇 등급인가요?
- [ ] 식약처의 AI 의료기기 허가·심사 가이드라인에는 무엇이 있나요?
- [ ] 비슷한 국내 허가 사례가 있나요? (예: AI 병리·영상 진단 보조)
- [ ] "진단 보조"와 "진단"은 규제에서 어떻게 다르게 취급되나요?

## 2. 유전정보와 개인정보

- [ ] 유전정보는 개인정보보호법에서 어떻게 분류되나요?
- [ ] 생명윤리법에서 유전자 검사·유전정보 활용에 어떤 규정이 있나요?
- [ ] 병원 밖 서비스(클라우드)에서 환자 변이 데이터를 받아도 되나요? 가명처리 등 조건은?

## 3. 책임과 설명

- [ ] AI가 제시한 후보가 틀렸을 때 책임은 누구에게 있나요?
- [ ] 의료 AI에 설명 가능성(왜 이 결과가 나왔는지)이 요구되나요? → 우리 "근거 유전자" 표시와 연결

## 4. 데이터 편향과 한계

- [ ] 학습 데이터(공개 암 유전체 데이터)의 인종·지역 구성이 한국 환자에게 그대로 맞을까요?
