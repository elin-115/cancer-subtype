## 문제
- 입력: 환자 한 명의 유전자별 변이 정보 (`WT` 또는 `V600E`, `R132H`, `S269fs` 같은 변이 표기)
- 출력: 26종 암 아형(SUBCLASS) 중 하나 (예: `BRCA`, `KIPAN`, `SKCM`) + 상위 3개 아형 확률
- 평가: Macro F1

## 폴더 구조
```
cancer-subtype/
├── (노트북 추가 예정)
├── assets/             # README 배너 등 이미지
├── docs/               # 문서 목록과 설명: docs/README.md
│   ├── 0x_*.md         # 팀 공통 (데이터 누수 규칙, 자료 조사 종합, 검토 체크리스트)
│   └── N_M_*.md        # 영역별 자료 (N = 영역 ①~⑥, M = 0 종합 / 1~ 개별 자료)
├── requirements.txt
├── data/               # 대회 데이터 (git에 올리지 않음)
└── output/             # 제출 파일, 모델 (git에 올리지 않음)
```

## 실행 방법
1. 데이콘에서 받은 `train.csv`, `test.csv`, `sample_submission.csv`를 `data/` 폴더에 넣습니다.
2. 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
   macOS에서 xgboost가 `libomp.dylib` 오류를 내면 `brew install libomp`를 실행합니다.
3. 노트북을 위에서부터 실행합니다. 데이터 경로는 첫 셀의 `DATA_DIR`에서 바꿉니다. (`01_baseline.ipynb`는 정리 후 추가 예정)

- v2에서 핫스팟 기준을 N≥5(573개)로 늘려도 CV는 0.4134로 비슷함. 리더보드에는 N≥5 버전을 제출함  
- v2에 경로 피처 10개(Sanchez-Vega 2018)를 더하면 0.4105로 효과가 없어 최종에서 뺌  
- 김지연 앙상블은 같은 변이 패턴 환자를 같은 fold로 묶어 CV를 더 엄격하게 쟀는데도 CV 0.456 → 리더보드 0.2982로 하락함. 섞는 모델(앙상블)은 이번 대회에서 리더보드를 올리지 못한다는 근거가 하나 더 생김  
- 여은지 v5는 fit_bias(OOF에 맞춘 클래스 보정)가 test에서 예측을 소수 클래스로 뒤집은 것으로 추정함. bias만 뺀 버전으로 확인 예정  
- 김새봄 변이 세분화는 CV가 v2-N5보다 약 0.03 높았지만 리더보드는 0.2937로 하락함. 피처 500개 선별은 fold마다 학습 부분 라벨로만 다시 해서 검증 라벨 누수는 없음(새봄님 확인). 원인은 학습 fold에 특화된 패턴 선택과, 세분화한 정확한 변이가 새 환자에서 다시 나오기 어려운 일반화 문제로 봄 → "단순한 있다/없다 피처가 가장 안정적"이라는 근거가 하나 더 생김  
- 여은지 v8은 CV가 v2-N5(0.4135)와 거의 같은데 리더보드는 0.042 낮음. 비슷한 D(끊김 0/1)는 0.3195였기 때문에 처음엔 test 전처리 버그를 의심했지만 최고점 파일과 예측 일치율이 75%로 D(78%)와 비슷해 버그는 아닌 것으로 봄. 가장 큰 차이는 최고점 파일이 COAD로 본 환자(test의 9.8%)를 v8은 대부분 STES로 옮긴 것(COAD 2.7%, STES 20.7%)  
- 치환쌍(PAIR)은 변이가 '어디'가 아니라 '어떻게' 바뀌었는지(돌연변이 흔적)를 넣은 피처. CV +0.036, 리더보드 +0.022로 v8A에 이어 CV 개선이 리더보드로 옮겨감. 형제 라벨 미사용  
- 김도엽 v8A는 피처를 더하지 않고 겹치는 라벨의 중복 행을 정리해서 학습한 것만으로 CV +0.011, 리더보드 +0.009. 핫스팟 이후 처음으로 CV 개선이 리더보드로 그대로 옮겨감. 오른 곳은 겹치는 네 아형(KIPAN 0.176→0.283, KIRC 0.271→0.373, GBMLGG 0.305→0.349, LGG 0.513→0.576). test 행을 train과 대조하지 않으므로 형제 라벨 교정과 다름. 최고점 파일과 예측 일치율 79.6%, KIPAN 예측이 129명 → 268명으로 늘어남  
- 2단계만 따로 붙인 실험(11/11 김지연, 중복 정리 없이)은 CV +0.0016에 그쳤음 → 효과는 2단계보다 **중복 정리** 쪽에서 나온 것으로 봄
