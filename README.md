## 문제
- 입력: 환자 한 명의 유전자별 변이 정보 (`WT` 또는 `V600E`, `R132H`, `S269fs` 같은 변이 표기)
- 출력: 26종 암 아형(SUBCLASS) 중 하나 (예: `BRCA`, `KIPAN`, `SKCM`) + 상위 3개 아형 확률
- 평가: Macro F1

## 폴더 구조
```
cancer-subtype/
├── (노트북 추가 예정)
├── assets/             # README 배너 등 이미지
├── docs/               # 문서 목록과 설명: docs/README.md
│   ├── 0x_*.md         # 팀 공통 (데이터 누수 규칙, 자료 조사 종합, 검토 체크리스트)
│   └── N_M_*.md        # 영역별 자료 (N = 영역 ①~⑥, M = 0 종합 / 1~ 개별 자료)
├── requirements.txt
├── data/               # 대회 데이터 (git에 올리지 않음)
└── output/             # 제출 파일, 모델 (git에 올리지 않음)
```

## 실행 방법
1. 데이콘에서 받은 `train.csv`, `test.csv`, `sample_submission.csv`를 `data/` 폴더에 넣습니다.
2. 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
   macOS에서 xgboost가 `libomp.dylib` 오류를 내면 `brew install libomp`를 실행합니다.
3. 노트북을 위에서부터 실행합니다. 데이터 경로는 첫 셀의 `DATA_DIR`에서 바꿉니다. (`01_baseline.ipynb`는 정리 후 추가 예정)

- v2에서 핫스팟 기준을 N≥5(573개)로 늘려도 CV는 0.4134로 비슷함. 리더보드에는 N≥5 버전을 제출함  
- v2에 경로 피처 10개(Sanchez-Vega 2018)를 더하면 0.4105로 효과가 없어 최종에서 뺌  
- 여은지 v5는 fit_bias(OOF에 맞춘 클래스 보정)가 test에서 예측을 소수 클래스로 뒤집은 것으로 추정함. bias만 뺀 버전으로 확인 예정  
- 노트북: `02_v2_hotspot.ipynb`(v2), `03_v1_핫스팟_비교.ipynb`(v3, 제출 파일까지 약 3분)
